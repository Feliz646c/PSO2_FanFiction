# 整理：狭間のトンネル、ユニエラの「お願い」、第1回の「ロシェを探して」（2026-11-11）

この資料は整理と提案であり、canonではない。第2回の導入でユーニの幻影が語った「作業」について、誰が何を頼み、何のためだったのかを、既存の資料から組み立て直した。資料で決まっていることと、空いている所を分け、空いている所には案を出した。

## 1. 資料で決まっていること

### 1-1. 第1回（2026-08-15）

- ロシェが目を覚まさない。ユーニは「ロシェはトランクの中で迷子になっている」「夢という形でトランクに入って、ロシェを探してほしい」と依頼した（第1回セッション情報 プロット・283〜395行）。
- ユーニの説明：中は「超超高密度の情報体の乱流」で、生身では身体が保てない。魂（夢を見る形）なら入れる。ユーニが誘導し、「楔」になる。ユーニ自身も仕組みは「良く知らね～」。
- 注意点の三つ目は「声に反応しないロシェがいたら、それは無視していい」。狭間では、近づくと消えるロシェの姿や、出口で「引き返せ」という声と顔のないロシェが現れる。
- 参加者はナベリウスへ落ち、ロアと出会う。「ロシェを探している」と告げると、ロアは名前に反応し、誰かと通信した（05 §2）。
- 結末で、ロシェは「……あれ？みんな昼寝？じゃあ私も寝る～～。」と言う（1852行）。第2回の導入では、ロシェは自力で目を覚ましていた、とされている。

### 1-2. 第2回（2026-09-11）の導入

ユーニの幻影が、PCには見えない相手と話す（08 §2【確定設定】PC達の到達経路、第2回セッション情報 415〜440行）。

1. ロシェがずっと眠りっぱなしなのは、この「作業」を始めてからである。第2回の企画メモには「ロシェが1週間ぐらい寝ていた原因が、この図書館を作る作業だった」とある（第2回セッション情報 81行）。ただし 08 は眠っていた期間を数値で書かないとしている。
2. 相手は「いけ好かねえやつ」で、ユーニを煽る。
3. ユーニ自身は狭間を単独で通り抜けられる。
4. それでも「バカでかい"トンネル"」を作らされている。目的は「呼び寄せるため」。ユーニは「理屈は分かるけどよ～」と言う。
5. 作業は"マスター"のお願いによる。
6. 最後の表情は、文句を言いながらも少し嬉しそう。

08 は、ここでロシェ・マスター・トンネルの正体を説明しない、としている。

## 3. 案

> **【2026-11-11 提案者の訂正】** ユーニの時系列は、**ロシェのトランクケースに落ちる → 統合世界でユニエラと契約を結ぶ → 参加者側の世界へ戻り、ロシェと知己になる**の順である。初稿の1（ロシェに懐いていてトランクに入り込んだ）は誤りなので、下の1・2を差し替えた。05 §3【確定設定】ロシェとの関係 の「ユーニがロシェのトランクケースに入り込んでいたのも、…単純に懐いていたためである」も、この順と食い違う（→ §6）。


上の空き所を、既存の決定を崩さずに一本の流れにした案である。

1. ユーニは参加者側の世界にいて、まだロシェを知らなかった。友達（シモン）とはぐれて迷ううちに、ロシェのトランクケースに落ち、狭間を抜けて統合世界へ落ちた。そこでユニエラと契約を結んだ。その後、参加者側の世界へ戻り、ロシェと知り合って懐くようになった（提案者、2026-11-11）。第4回の導入の幻影（「シモン～……どこだ～……」「なんでトランクケースがこんなとこに繋がってんだよぉ……」）は、この最初の落下の場面である。
2. ロアは、ロシェの記憶を手掛かりにユニエラを訪ね、そこでユーニに会う。ユーニは二つの世界を行き来できる。ユーニの口から「ロシェってやつのトランクに落ちたら、こっちに着いた」「向こうでロシェは、友達とわいわいやってる」と聞く。会ったのがユーニとロシェが知り合う前なら、ロアは「トランクケース」の話からロシェに辿り着き、後でユーニに確かめさせる形になる。どちらの順でも、ロアが夢のロシェを知るのはユーニ経由になる。**ロアはここで初めて、ロシェが別の世界で夢を見ていて、そこに縁のある人々がいることを知る**（A1の案）。ロアの知識は世界外へ去るまでなので、夢のロシェを知るのはユーニ経由、とすると知識の範囲が守れる。
3. ロアはユニエラに「その人たちを、こちらへ呼びたい」と頼む。理由は話さない（院長への備え、05 §2）。
4. ユニエラはこれを、自分の研究として引き受ける。別の世界から人を呼ぶ道は、世界の成り立ちを知る手掛かりであり、漂流者を帰す研究にも直結する（A2の案）。ユニエラはユーニに「通り道を作ってほしい」と頼む。
5. 「呼び寄せるため」は、参加者を統合世界へ呼ぶことを指す。ユーニ一人なら狭間を抜けられる。しかし、夢の形で入る大勢の魂は、情報の乱流の中で迷う。だから、太くて迷わない道（トンネル）が要る。ユーニの「理屈は分かる」は、この仕組みのことである（A3の案）。
6. トンネルは、ロシェのトランクケースの中（狭間）を掘って作る。トランクケースは夢のロシェの常設の空隙なので（01 §2-5、06 §1-5）、作業の間、夢のロシェは眠ってしまう。仕組みは卓上で説明しない（A4の案）。
7. 第1回の時点で、トンネルはまだ途中である。ユーニは「この作業を始めてからロシェが眠っている」ことは知っているが、なぜかは知らない。「ロシェを探してほしい」は半分本心で、半分は口実である。ロシェが起きないことは本当に心配している。同時に、参加者を夢の形でトランクに入れ、途中の道を通して統合世界へ届けることが、ロアとの約束でもある（A5の案）。第1回のユーニの「良く知らね～」は、仕組みを知らないという意味では嘘ではない。
8. 「いけ好かねえやつ」はロアである（A7）。マスターの後ろで頼んでくる相手で、目的を言わない。煽ってユーニに作業を続けさせる。
9. 第1回の後、ロシェは自力で目を覚ます。作業が一区切りしたためである。トンネルは第3回までに完成した。以後、参加者が通るたびに道が踏み固められ、第4回の時点では安定している（U6）。
10. 狭間の「引き返せ」という声と顔のないロシェ（A6）は、眠っている夢のロシェの意識の名残とする案がある。ロシェ自身は、自分と繋がっている者を巻き込みたくない（01 §2-6、05 §15）。眠りの中でも、トランクに入ってくる者を押し返そうとする。第4回の導入の「ここには何もないよ　引き返して」も、同じ反射として読める。

## 4. 批評

総評：既存の決定（05 §2〜4、ブレスト_08 のB案、U6）を一つも崩さずに繋がった。一番効くのは2（ロアが夢のロシェを知るのはユーニ経由）で、ロアの知識の範囲と、ロアとユニエラ・ユーニの出会いが同時に埋まる。弱いのは6と10で、ロシェの眠りと狭間の声に、仕組みを一段足すことになる。

1. 【深刻度：中】10 は世界外ロシェの扱いに触れる

   「眠りの中でも押し返そうとする」は、世界外ロシェ（夢を見ている本体）の意思が狭間に出ている、と読める。ロシェの最終段階の動機（縁を切りたい、05 §15）を、第1回・第4回の時点で匂わせることになる。別スレッドのエンディング新案とも関わるので、採るなら向こうと揃えたい。採らない場合は、声の正体を未決のまま残してよい。

2. 【深刻度：中】7 の「半分口実」は、ユーニの印象を変える

   第1回の依頼が口実を含むと、ユーニがPCを騙したことになる。ユーニは他所のキャラクターなので、人柄に関わる部分は所有者の感覚と合うかを確かめたい（ユーニの性格は提案者に一定の裁量がある、とブレスト_08 §5 にはある）。

3. 【深刻度：低】6 の「作業の間ロシェが眠る」

   第2回の企画メモの「原因」を、トランクケースが空隙であることから説明した。卓上では説明しないので実害はないが、作業が今も続くなら、ロシェは今も眠りがちになる。第4回時点でトンネルが完成していることと、ロシェが起きていることが合うかを確認したい。

4. 【深刻度：低】2 の「ロアはユーニ経由で夢のロシェを知る」は新しい事実

   05 §4 は「ロアが知るのは世界外へ去るまでのロシェ」とだけ書いている。ユーニ経由で夢のロシェの存在だけを知った、と足すことになる。夢のロシェの日常までは知らない、と線を引いておくと、05 §4 の「この違いが最終的に重要」も崩れない。

残すべき点は、5 の「ユーニ一人なら抜けられるが、大勢の魂は迷うのでトンネルが要る」である。第1回のユーニの説明（乱流、楔、誘導）と、第2回の「理屈は分かる」が、同じ仕組みで説明できる。

確認した範囲は、第1回セッション情報（プロット、283〜395行、1852行）、第2回セッション情報（プロット 77〜85行、415〜440行）、第3回セッション情報（プロット）、canon/08 §2、canon/01 §2-5・§2-6・§3-4、05 §2〜§4・§15、ブレスト_07 §7、ブレスト_08 §5〜7、ブレスト_15 §5 である。第1回・第2回の実ログ（.docx）は今回開いていない。

## 5. 決めたいこと

§3 の流れでよいか。特に、2（ロアが夢のロシェを知った経路）、7（第1回の依頼は半分口実か）、10（狭間の声の正体）の三点。

## 6. 05 §3 との食い違い（2026-11-11 追記）

05 §3【確定設定】ロシェとの関係 は、「ユーニがロシェのトランクケースに入り込んでいたのも、ロシェに付き従う義務があったからではなく、単純に懐いていたためである」と書いている。提案者の時系列（落下→ユニエラと契約→戻ってロシェと知己に）では、最初にトランクへ落ちた時点でユーニはロシェを知らない。

直し方の案は、05 §3 の当該文を「ユーニが最初にトランクケースへ落ちたのは偶然であり、ロシェと知り合う前である。統合世界でユニエラと契約を結んだ後、参加者側の世界へ戻ってロシェと知り合い、懐くようになった」に差し替えることである。「懐かれている、仲の良い姉妹のような間柄」「マスターと使い魔の関係ではない」はそのまま残す。旧文は changelog へ移す。
