# ヴェンデッタ

本編と世界観が軽くつながる外伝。

外伝共通のルール(本編資料は参照のみ、など)は `side-stories/README.md` に従う。

## 概要

惑星エクシルを舞台にした外伝。失敗作と断じられた模倣全知存在(コピーシオン)が星そのものへと転化し、神「オディーニア」を名乗って、フォトナーを超える完全種を創るための創生実験「Project ARK」を続けている世界の物語。宗教都市国家ワルプルギスと機械都市国家エクスマキナが戦争状態にある。

詳細は現状たたき台のみ → `drafts/01_たたき台_概要と用語.md`
