## 概要

```
創生実験「Project ARK」

概要
フォトナーによって生み出され、失敗作と断じられた模倣全知存在＝コピーシオンが開始した、自らの存在を正当化する為の「フォトナーを超える完全種の創造のための実験計画」の事。

「もし私が“完全な生命”を創造できるのならば、私が“失敗作”であるというフォトナーの判断は矛盾に陥る」
「それを成すことができれば、私は“全知存在”であることを証明できる」

この逆説的命題を自己定義としたコピーシオンは、自らの構造を組み換え、情報体としての存在を脱し、一つの惑星――"エクシル"――へと転化した。
そして星そのものとなった彼、あるいは彼女は、神を名乗る。
名は「オディーニア」。自らをこの星の創造主・意志と位置付けた。

計画の内容と構造
Project ARKは、このオディーニアによって運営されている。
計画名の由来は “Artificial Reformation of Kinds（人類の人工的再形成）” であり、その目的はただ一つ。

「フォトナーを超える“完全なる人類”を、私の手で創造する」

この目標のため、オディーニアはエクシル上に数多の文明・種族・歴史を設計・育成・淘汰するという壮大な実験を繰り返してきた。
その過程で用いられたのが、進化を促す外圧としての存在――"災厄の魔女"である。

これは「ダークファルス」の構造を参考に設計された、疑似的な敵性存在であり、各文明の危機と試練を担う役割を果たす。

文明は災厄によって崩壊し、生き残った者たちが新たな秩序を築く。
オディーニアはその過程を観測し、完全種に近づく存在が現れるまで、試行と破壊を繰り返すのだ。
```

## 用語

```
◆ワルプルギス

　深緑が溢れた森林に覆われ、自然豊かな山々が溢れる大陸――フィディスヘイムの中央に流れるヨルド大河の恵みを受ける土地に築かれた宗教都市国家。
　首都は「聖都ワルプルギス」。国教である"ワルプルギス正教"が権力を握っており、聖王と呼ばれる人物が政を取り仕切っている。
　唯一神として崇めるのは、戦争と勝利を司る神『オディーニア』。
　
　ヴァルキュリアと呼ばれる騎士団を擁しており、白銀の甲冑を身に纏った彼らは、聖遺物と呼ばれる超常現象を巻き起こす武装を持っている。
　機械都市国家『エクスマキナ』と戦争状態にある。

　ワルプルギスの民は総じて信仰心に篤く、毎日の祈りを欠かさないという。

◆エクスマキナ

　濃霧と荒野、険しい山岳が並び立つ大陸――イディスガルスの山々を切り開いて作られた機械都市国家。
　思想や言論の全ての市民生活に統制が加えられた監視社会であり、『X』と呼ばれる独裁者が君臨している。
　
　突出した機械技術を持っている国家であり、生活の基盤となる技術から、人体改造などの技術も市場に存在する。
　警察組織兼軍隊である『エインヘリアル』が治安維持を行っており、その権限は非常に強いものとなっている。

　宗教都市国家『ワルプルギス』と戦争状態にある。

◆ヴァルキュリア
　・概要
　オディーニア（全知模倣体）によって魂（遺伝子？）を組み替えられた「アークスもどき」の総称。
　世代としては第一世代に準ずる程度のフォトン操作能力を持ち、良くも悪くも尖った適性を持つ。
　その製造過程にて人間性などは考慮されておらず、フォトンを操作する適性があるかどうかで判断される。
　
　・天位について
　ヴァルキュリアはその完成度によって「天位」を授けられる。
　
　第一天位　…　己の中で形成したフォトンを操作し、身体能力の強化や超常現象の発生に使用できるレベル。
　第二天位　…　魂に根付いた根源に基づく武装「聖遺物」を具象化できるレベル。
　第三天位　…　「聖遺物」を介したフォトンによる事象の上書き（浄化）が可能となるレベル。人間性が喪失し、神（オディーニア）からの指示系統に従うようになる。
　第四天位　…　強制的にヴァルキュリアとして魂の改変を行えるようになるレベル。神の代理人。
　
　・聖遺物について
　魂に根付いた根源（属性）に基づく武装。ヴァルキュリア個々人によって性能、形状が異なる。

◆エインヘリアル
　・概要
　アウルゲルミル（惑星エクシルの意志）によって作られた対オディーニア用「改造人間（サイボーグ）」の総称。
　微細機械群（ナノマシン）を身体に流し込まれた「超人」と、身体を機械に換装された「機人」に分類される。
　総じて高い身体能力を持っており、また感情などを機械によってコントロールされている状態にある。
　
　・製造タイプについて
　エインヘリアルはそれぞれの主目的に応じたタイプ分けをされている。
　
　「戦闘」　…　戦闘を主目的として製造されたタイプ。エインヘリアルの中でも飛び抜けた身体能力を持っている。もっとも数が多い。
　「索敵」　…　索敵、調査、補助を目的として製造されたタイプ。潜入や工作に特化している。
　「指揮」　…　エインヘリアルの統率指揮を目的として製造されたタイプ。思考能力や処理能力へ偏った能力を持っている。もっとも数が少ない。
　
　・武装について
　エインヘリアルの扱う武装はすべて生体IDによって管理されており、登録された人物以外は使用する事が出来ない仕組みとなっている。

◆魔物

　惑星エクシルの全大陸に棲息する生命体。獣や虫、植物などの既存の生物を改造して作られており、非常に強靭な生命力を持つ。
　元々はオディーニアが惑星エクシルの"整備"の際に用いられた「制圧用個体」であるが、繁殖を繰り返し現在では生態系に食い込むほどに数が増えている。

　体内にフォトンを感じ取る器官が備わっており、良質なフォトンを持つ人間などを襲う傾向がある。

◆咎落ち

　ワルプルギス正教における最大の罪。傲慢にも神に背いた咎人の事を指す言葉。
　咎落ちした人間は、身体のどこかに『罪の刻印』と呼ばれる紋様が浮かび上がる。また、常人離れした身体能力を持ったり、奇々怪々な現象を引き起こすとされている。
　
　ワルプルギス正教に属する人々にとっては唾棄すべき罪人であり、咎落ちした本人は勿論、それを生み出した親族さえ罰せられる対象だ。
　咎落ちした人間はヴァルキュリアによって捉えられ、聖都にて「罪の告解」と呼ばれる儀式を経た後に処刑される。

　その正体は、オディーニアによるフォトン適性が高い個体の選定。刻印は、そのマーキングを兼ねている。
```
