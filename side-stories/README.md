# side-stories（外伝）

本編と世界観が軽くつながる外伝作品の置き場。外伝ごとの設定・下書き・本文の正本はここに置く。

## ルール

- **本編の資料は参照のみ。** 外伝の作業で `canon/`・`changelog/`・`sessions/`・`stories/` など本編側のファイルを書き換えない。
- 外伝の設定は本編の正史ではない。外伝で決めたことを本編 canon へ持ち込むときは、本編側でユーザーの確定・反映指示を受けてから行う。
- 本編 canon の【確定設定】と矛盾する外伝設定を作る場合は、意図的な差異かどうかを外伝側の資料に明記する。
- 本編でGM専用・非公開として区分された情報を、外伝の資料へ書き写さない。

## 構成

外伝作品ごとにディレクトリを分ける。ディレクトリ名は作品名の英語表記（小文字・ハイフン区切り）にする。

```
side-stories/
├── README.md          # このファイル
└── <作品名>/
    ├── README.md      # 作品の概要・本編とのつながり
    ├── canon/         # 外伝の確定設定（必要になったら作る）
    ├── drafts/        # ブレスト・検討中の案
    └── stories/       # 本文
```

作品内の構成は目安。作品ごとに必要なものだけ作ればよい。
