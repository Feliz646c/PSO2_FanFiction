# 整合性チェック

対象（変更案・PR・台本・本文など）を、既存資料と突き合わせて矛盾を探す。
**このスキルでは資料を書き換えない。** 指摘と根拠を返し、直すかどうかはユーザーが決める。

## 確認する資料の優先順位
1. 開催済みセッションについては `sessions/logs/` の実ログが最上位。
2. `canon/00〜03`（世界の公理）。
3. `canon/06〜08`（00〜03に従属）。
4. `sessions/開催セッション/05_統合世界セッション構想.md` と各回のセッション情報。
5. `drafts/` は正本ではない。参考にだけ使う。
`changelog/` は「過去に何が撤回されたか」を調べるときだけ読む。現行設定の典拠にしない。

## チェック項目
- **公理**：00〜03の【確定設定】と矛盾しないか。
- **時系列**：年齢・年代・出来事の前後関係がずれていないか。旧世界と現世界の区別。
- **因果**：その出来事が起きる理由・結果が、既存設定から説明できるか。
- **人物**：キャラクターの思想・口調・能力の制限と合っているか（canon/01・06）。
- **ステータス**：【有力案】【未決事項】を確定扱いしていないか。逆に【確定設定】を黙って変えていないか。
- **公開範囲**：GM専用・非公開の情報が公開資料（03など）に出ていないか。
- **連動**：08⇔05の食い違い。
- **用語**：02に未登録の固有名詞、既存用語と紛らわしい名前。

## 出力形式
指摘ごとに次を書く。
- 種別（公理／時系列／因果／人物／ステータス／公開範囲／連動／用語）
- 対象の該当箇所
- 食い違う既存資料のファイル名・節・該当文
- 深刻度（矛盾／要確認／軽微）
- どちらが誤りか断定できない場合は、両方の可能性を書く
