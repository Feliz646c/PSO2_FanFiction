# 台本精査

## 情景描写（`#` で始まる地の文）のルール（2026-10-08 ユーザー指示）
- **事実を列挙する。** 物・音・光・人物の動作を短く並べる。
- **PCの行動・思考・感覚を決めつけない。** NG例：「〜を見上げる」「見覚えがあるだろう」「〜な気がした」「言葉が追いつかない」。
- PCの反応はGM注記「（RPの時間を取ります」でPL側へ渡す。
- PCに感覚を与える表現は、canonで文言が固定されたもの（例：ルディアの「頭の痒み」）だけにする。
- **不穏な印象を与える描写を入れない。**

## 確認すること
1. 上の描写ルールに反する箇所。
2. NPCの台詞・行動が canon/01（人物）・06（能力）と合っているか。
3. 開催済み回の内容に触れる場合、`sessions/logs/` の実ログと合っているか。
4. 参加者側のキャラクター・世界の恒常設定を、台本で断定していないか（参加者に帰属する設定は観測できる事実だけ書く）。
5. GM専用情報がPL向けの描写に漏れていないか。
6. 必要なら `consistency-check` スキルで全体の整合を見る。

## 出力
- 指摘は「該当箇所／理由／修正案」の形で並べる。
- 書き換え版を作る場合は、元ファイルを直接上書きせず、作業ブランチでコミットしてPRにする（差分で確認できるようにする）。
