# canon反映

ユーザーが「確定」「反映してよい」など明示的に確定した設定を、canon本体へ反映する。
確定発言がない内容（【有力案】【未決事項】、AIの提案）は反映しない。迷ったらユーザーに確認する。

## 手順

1. **根拠を確定する。** 反映する内容と、ユーザーの確定発言（日付・スレッド・文言）を書き出す。
2. **作業ブランチを切る。** 例：`docs/canon-<対象>-<YYYYMMDD>`。1テーマ1ブランチ（AGENTS.md §12）。
3. **影響範囲を調べる。** 対象の固有名詞・キャラ名で `canon/`・`sessions/`・`changelog/` をGrepし、関係する節を全部挙げる。
4. **本体を更新する。**
   - 本体には現行の設定だけを書く。ステータス見出し（【確定設定】【確定方向】【有力案】【未決事項】）を付ける。
   - 撤回・差し替えがある場合は、旧本文を本体から削除する。「今後こう書くな」という禁止事項は【確定設定】として本体に残す。
5. **【更新履歴】を追記する。** 本体の【更新履歴】の先頭に `YYYY-MM-DD(n)── 見出し` 形式で書く。
6. **changelogへ移送する。** 削除した旧本文を `changelog/` の同名ファイルへ原文のまま追記する。見出しは本体の【更新履歴】と一字一句同じにする。GM専用・非公開の区分は引き継ぐ。
7. **連動確認。** 08を変えたら05、05を変えたら08を確認する。00〜03と矛盾しないか確認する（`consistency-check` スキル）。
8. **設定台帳を更新する。** `drafts/設定台帳.md` の該当行を直す。台帳は索引であり正本ではない。
9. **コミットしてPRを出す。** PR説明に、根拠の確定発言・変更箇所・ステータスの変化・未解決の矛盾を書く。Mergeはユーザーが行う。

## 注意
- 既存の【確定設定】を変える必要が出たら、編集前にユーザーへ理由を示して確認する。
- 撤回直後・議論中のものは、本体に残してよい（CLAUDE.md「硬直させないための例外」）。
- 新しい用語は `canon/02_用語マスター.md` に登録があるか確認し、未登録ならPR説明で明示する。
