**オメガとは何か（2026-09-02・作者決定済み）**

原作の「アカシックレコードが見る夢」は**不採用**。本作のオメガは：

> **ロシェの中で眠るハリエットが、ロシェが壊した世界の残骸を器として受け止め、その材料で組み上げた「彼女が見たかった世界」。**

**作者が決めた8点：**
1. 情報が器へ流れ込む機構＝**追加機構なし**。「アカシックレコードを収容可能な器」という**既存の設計目的がそのまま働いただけ**。ユニオラルの逃がし弁案は**不採用**。
2. ハリエットは**無自覚**。→**遡行召喚で自覚**。
3. オメガ・ハリエットは**別人格として育ち、遡行召喚で統合**された。（＝2と3は遡行召喚という単一の出来事。ルーサー編中盤。01 §8-1「EP5で目覚める」の内実がこれ）
4. ロシェが真相を知るのは**エルミルの宣告時、ただし薄々気付く程度**。完全な理解には至らない。
5. **エルミルは全て知ったうえで、意図的に不完全な答えを与えている。**ただし01 §1-1の「ロシェの個人史は知らない」は維持。
6. **ブラックホール要素は不使用**（00 §3-52の「外部からのシバ帰還はない」と併せて）。
7. **縁還りとは切り分ける。**オメガが在ったのは「覚えていたから」ではなく「器だから」。奇跡性を保つため先例にしない。
8. オメガ深層の正式名称＝**「記憶深層」に確定**。

**決定打の因果（作者提示）：EP3でロシェがロアを斬った＝ロアの起源世界（後の遺界）を滅ぼしたのはロシェ本人。** ロアは世界一つ分の歴史を収容した容器だったため、初めて「断片」ではなく「完結した歴史」が器へ落ち、器の中の情報が世界の形を取り始めた。

**帰結（提案に使える）：**
- オメガに原作PSO2の人物・事件が存在する理由＝**ロアの世界の再現だから**（メタな都合が作内因果になる）。
- ヴェルン編のシーナ／ゲッテムハルト／シュレッガーは**ロア世界由来の情報**が素材。旧世界で十年前に死んだシーナ本人ではない。
- 虚実混合＝記憶深層（未加工の実）／ハリエットの記憶による補完／願望。判定は「本物か」ではなく「どの部分がどこ由来か」。
- 半確立は起きない（オメガはACの枝ではない／ロシェの所在は旧世界のまま）。02無改訂。

**How to apply:** オメガ関連の提案は必ずこのモデルを前提にする。特に「ロシェが壊した世界の住人が生きて目の前にいる」がEP5の感情エンジン。
