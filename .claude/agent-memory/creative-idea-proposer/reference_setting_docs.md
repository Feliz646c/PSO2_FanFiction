- 設定資料は `設定資料\00_世界設定マスター.md` 〜 `05_統合世界セッション構想.md`。番号は依存順。00〜03が公理、04はカジノ編個別構想、05は04を包含する上位構想。
- 実際のセッションログ・台本は `個別資料\<日付>セッション\` 以下にあり、05の記述の根拠になっている（例：第1回統合世界セッション、カジノ編、カラオケ編）。05の内容を疑う場合はここが一次情報。
- 編集者エージェントの記憶は `.claude\agent-memory\creative-editor\` にある。特に `project_open_consistency_issues.md`（未解決の整合性論点）と `project_revision_decisions_20260828.md`（蒸し返さない決定事項）は、提案が既に潰れた案を再提出しないために有用。
- 用語は02が正本。新規固有名詞を使う場合は02未登録であることを提案内で明示する（CLAUDE.mdのルール）。

**How to apply:** 最終決戦・カジノ編など05/04にまたがる提案を出す前に、editor側の未解決論点メモを読んで重複と既否決案を避ける。
