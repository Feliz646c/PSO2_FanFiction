**確定した核（2026-09-10、作者が好評価）：** 04§7の残響物（コルネオ所有／因果偏向型）の射程問題は、「**参加者は夢を経由して統合世界にいる（04§1・05§2確定）＝生身ではない。よって送還は世界間移動ではなく覚醒であり、『夢が覚めるか否か』という未確定の局所事象への偏向にすぎない**」で解決した。新機構ゼロ。作者からは「セッション運用上の『切り上げタイミング＝覚醒』とも合っている」と評価された。**ただしファイル反映は未実施（練り上げ段階）。**

**Why:** 04§7【編集メモ】と04§15【重要：説明させないこと】が作中での解説を明示的に禁じている。この解を採ると「未整理だから伏せる」ではなく「確定しているが開けられない（開けると"肉体ごとそこに居ない"という別のネタバレが同時に開く）」へ昇格する。

**How to apply:**
- 正体はGM内部設定に置く。03カタログは統合世界の公的記録なので本文に書けない。現物はフィクスが持ち去るため「記録：オラクル研究記録」も付かない。
- **意匠の種（作者発、2026-09-10）：ケースに入ったサイコロ。** 台本の「身に着けた残響物」「無造作にかざす」と両立する手のひら大の筐が前提。04§7確定は「場全体の未確定事象への偏向」なので、**賽の目が結果を決める小道具にはできない**（§12の「攻撃が外れる」が説明不能になる）。賽は計器／縮図／触媒のいずれかに留める。提案した三方向：①計器（読み取り窓）②縮図（未確定を六面へ丸める）③止まらない賽（常に回り、確定した瞬間だけ止まる＝送還時に一度だけ止まる画が作れる）。
- 02の「ロシェのトランクケース」とは**別物**。手のひら大 vs 旅行鞄で峻別し、呼称も分ける（トランクケース／賽筐）。02【最重要・確定設定】「接点は所在ではない」には触れない＝この筐は世界外と繋がらない・空隙ではない、とGM内部で言い切る。参加者が誤想する余地は残してよい（誰も答えない方針と相性が良い）。
- **院長による意図的流出（作者発の種）：** 01確定「コルネオは院長の組織に所属しない独立した犯罪者」を壊さない渡し方が要る。**「賭けでコルネオに勝たせて巻き上げさせる」＝院長は渡していない、奪わせた**という手口が、01「他者の傷や欠落を利用する」勧誘手法と同型で最も安全。仮説は①実地試験（原理上、意図を持って観測すると測れないため野良で回すしかない）②撒き餌（誰が寄ってくるかを見る／実際に釣れたのがロア）③嫉妬の物差し（局所偏向程度は院長には"小銭"だったので手放した）。
- **04§15・§17【未決事項】「院長が最終的に何へ使うのか」は開けないまま流出設定だけ確定できる。** 用途を決めると「なぜ院長はこれで勝てないのか」の恒常的な説明負担が生じる（批評フェーズで最も当たられる線）。入手経路と用途は切り離しておくのが安全。
- 台本（個別資料\20260911セッション\セッション情報.md）のフィクスの現行台詞は「頼まれたから持っていくだけだ」。作者が言う「正しく使える奴のところへ渡す」は未記載＝追加候補。これは残響物の性質の解説ではないので§15【説明させないこと】には抵触しない。
