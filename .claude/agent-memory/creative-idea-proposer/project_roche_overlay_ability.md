**2026-09-02、作者が確定。**「世界線の重ね合わせ」を正式設定化。名称は**重畳《かさね》**（仮称確定）。

**最終イメージ（作者の言葉）：**
> 現実というテクスチャーを不安定化（破壊）させたうえで、その空隙に可能性世界の事象をコピペ（重ね）している。

**＝抽出ではなく複製。参照元は何も失わない。外部代償なし。**

**三段構成：**
- 前提**《観測》**：隣接する並行世界の記述を受け取る（器由来の受動的性質。**探しに行く能動的アクセスではない**）
- 工程①**《綻び》**：その場の現実の記述を局所的に不安定化させ空隙を作る（ロシェ由来）
- 工程②**《重ね書き》**：空隙へ参照した記述を重ねる（器由来）

**確定事項：**
- **代償なし。**《欠け》削除。旧称《開路》《引き出し》《併在》《持ち出し》も不採用。
- 制限は4つのみ：①実在する記述しか重ねられない ②空隙は一度に一つ ③連用不可・**危険はこちら側**（実セッションでロシェが「あ、やばっ」でトランクを閉じた実績あり） ④差の大きい記述は不可。
- **定着の持続性／死者への適用／自己適用の可否は【未決事項】。**確定させない（「使える」と積極的に確定もしない）。
- **《綻び》は段階表の外。**単体では何も達成せず放置すれば閉じる＝規模を持たない。段階2・3（世界境界／世界そのもの）とは無関係。
- **《観測》は世界境界を越える行為ではない。**隣接する記述を受け取るだけ。00§3-23「能動的アクセス機能は無い」を踏まない。
- **したがって縁還り後も重畳は残る。**06§1-4の転嫁喪失・段階2/3喪失は変更しない。失うのは「世界を終わらせられること」であり、重畳は世界を壊せないので別物。
- **トランクケースは二役。**①世界外との接点（決着で終了）②常設の空隙（**決着後も残る**）。閉じない。
- 旧世界で発現しない理由＝当時は受け取った記述が全部内側の器へ溜まっていた（00§3-14＝オメガの材料）。**本編への影響ゼロ。**
- 決着の一行：**失うのは世界を終わらせられること。残るのは目の前の一点を書き換えられること。兵器ではなく手当て。**

**How to apply:** 「引き出す／持ってくる／奪う／借りる」は禁止語彙。「綻ばせる／重ねる／写す／書き換える」で統一。**作中で能力の詳細を知る人物は少数**のため、台詞例を資料へ書き足さない（作者指示）。
