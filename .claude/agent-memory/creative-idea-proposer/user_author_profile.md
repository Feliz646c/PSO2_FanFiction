作者は「PSO2二次創作の長編構想」と「共同セッション（統合世界セッション／カジノ編等）」を同時に運営している。設定資料を00〜05の番号付きで厳密に管理し、【確定設定】【確定方向】【有力案】【未決事項】のタグで状態を区別する運用に慣れている。

**協働スタイル：**
- proposer（提案者）／editor（編集者）／critic（批評者）のサブエージェントを役割で使い分けており、提案者には「批評ではなく可能性の拡張」を期待している。
- 編集者や批評者の指摘を叩き台として提案者へ回す運用をする。他エージェントの案を土台にしたうえでの補強案・代替案を求められる。
- 複数案＋各案のメリット／デメリット（トレードオフ）を明示する形式を明確に要求する。デメリットは価値判断ではなく「この案を採ると説明が必要になること」として書く。
- 00〜03は「世界の公理」として書き換え不可。提案は05や02の用語定義側で成立させるよう指示される。

**How to apply:** 提案は抽象論で止めず、具体的な場面・台詞・固有名詞・その場面が生む感情効果まで書く。新規固有名詞は「02未登録」と明記する。セッション用途があるため、参加者（PC）全員に見せ場が回る構造かどうかも判断材料として添えると価値が高い。
