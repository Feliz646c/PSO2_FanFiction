00〜03は「世界の公理」。提案は原則05／02側で成立させる。特に踏み抜きやすい線：

1. **シバ＝ロシェは完全同一人物。** 別人格・憑依・上書きではない。「ロシェの中のシバ」は禁止（「ロシェの中にハリエット」は正しい）。シバとロシェを分離する解決案は作らない（05 §8に明記）。
2. **ロシェの能力は「破壊」のみ。創造しない。** 扉を作らず境界を壊す。何を残すかを新しく定義できないため、救済には必ず本人の抵抗＋周囲の支援が要る。ロシェ単独万能解決にしない。
3. **統合世界にロシェは存在しない。** 世界外で眠っている。第4母艦《シバ》は本人でもコピーでもなく「空の器・帰る場所」。
4. **統合世界の人物は統合世界生まれ。** 復活・転生・移住ではない。例外はロア／ジーヴル／ゲルニカ／フィクス／ミラーズの「別世界の自己情報」のみ。
5. **00最終章の三つの不成立解**：自殺＝根本解決にならない／封印＝古代ハリエットの再演／別世界への逃亡＝因果を持ち込むだけ。ここと矛盾しない説明を必ず用意する。
6. **テーマ**：自己犠牲そのものは否定しない。否定するのは**他者から用途を与えられること**。「生まれた理由と、生きる理由は同じではない」。役割ゆえの犠牲を美談化しない。
7. **ロシェの破壊の前例**（提案の足場に使える）：黒き邪竜＝生命と世界の結合、ルーサー編＝人格とDF因子の結合、ヴェルン編＝人物と憑依存在の結合。いずれも「結合を壊し、残すものは本人と周囲が支える」構造。

**How to apply:** 新機構を提案するときは、必ず上記5と7に接続して「なぜ自殺は無効で、この方法は有効か」を1〜2行で言い切れる形にする。
