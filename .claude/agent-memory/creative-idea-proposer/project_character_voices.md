**口調・声：**
- ロシェ：眠たげで無造作、二人称「アナタ」、文頭に「……」。決め台詞は短い。例「……私の世界を守るためなら、アナタの世界を壊す」「もうちょっとだけ、寝かせて」「今日はどんな景色が見れるかな」。
- ロア：口下手・不器用。感情が表情に出ず説明を省略する。自嘲的で短い。例「……『ずっとこの日を待っていた』、か」「――柄じゃないね」。
- ユニエラ：「――」を多用する温かい学者口調。「――ヒトは醜いと思うかな。世界は歪んでいると思うかな……」
- カージュ：断定形の思想語。「これは俺の命だ。俺が決める」「お前の命だ。俺のために使うな」。
- ルディア：享楽的・高速。「あは、生まれた、生まれた！」

**演出資源（既存設定にあり、まだ使い切られていない小道具）：**
- ラルの私的な詩集。ロアは内容を暗記しており、本気で良い詩だと思っている（01）。
- ロアの左眼球喪失。義眼等で補填していない＝空洞のまま（01）。
- ユーニは「一キャラにつき一人のマスター」が成立する座敷童型の人形。ロシェのトランクへ入り込んで統合世界へ落ち、ユニエラをマスターにした（05）。マスターの移動＝縁の可視化に使える。
- ロシェのトランクケース＝観測可能な並列世界の可能性を持ち出す残響物（03/02）。
- コルネオの因果偏向型残響物（04）。ロアが調査していた対象。
- EP3の対決台詞「……私の世界を守るためなら、アナタの世界を壊す」は反転させる余地が最大の一行。
