## セッションの実運用フォーマット（第1回・カジノ編から読み取れる型）

- **尺は180分（21:30〜00:30）が実績値。** カジノ編は210分案から180分へ調整された経緯がある。台本には「タイムスケジュール厳守／巻きが必要なら台詞・描写から優先的にカット」と明記される。
- **判定系は 1d100＋RP補正 ≧ 目標値。** 補正はGMがRPを見て裁量で決め、上限を場ごとに設定する。参加者が既に慣れているため、**新規ルールを増やさず同じ骨格を流用できる**のが強み。
- **台本の書式：** `#`＝地の文、`/toge` `/moya`＝演出タグ、`（ ）`＝GM発言、`『 』`＝思考会話（《同一化》の秘匿通信）。BGMのYouTube URLをシーンごとに差し込む。Cスペース移動で場面転換する。
- **演出の哲学が徹底している：** 「一度だけ描写して説明しない」「2往復で打ち切る」「説明台詞を置かない」「PCを必ず一度勝たせる場面は削らない」。断片だけ置いて解説しないのが作者の型。
- 参加者はハルファ（NGS）側のPCで、**夢を経由して統合世界へ入る。** 第1回＝ナベリウス、第2回＝第76番艦《フォルネア》のカジノ。導入は「狭間の図書館」→"窓"で場面転換。ユーニは**フリップで喋る**。

## 第3回：《ミラージュ》兵装実験場編（2026-10-09予定）の骨子

作者から与えられた展開順序（変更不可）：夢経由で到着（3回目で慣れている）→ 警報 → アヴリスの襲撃 → 気付いて戦闘終了 → ルディア登場・会話 → 漂流者登録の話 → スピーカーからミラーズ（力を自社技術へ組み込みたい／交換条件に模擬戦）→ ルディア＋アヴリスのタッグ模擬戦 → カージュ乱入で模擬戦 → ミラーズと模擬戦 → 《ミラージュ》との協力関係が成立して終わる。

**核＝4人の確定能力（《同一化》《重力からの解放》《蝕み》《連結決算》）を模擬戦で初めて可視化すること。**

### 提案時に効いた勘所（2026-09-18 提案）

- **カージュ戦は「触れられたら即敗退」ルールにすると、蝕みを一度も使わせずに蝕みを見せられる。** 解除・治療の可否（06 §3-4【未決事項】）を踏まずに済み、「これは俺の命だ。俺が決める」＝使わないことを選ぶ、という人物の意思で説明できる。
- **ミラーズ戦は「PCの攻撃がそのまま相手の資産になる」逆転テンポ。** 帳簿を公開カウンターにし、長引かせる側＝ミラーズ／早く終わらせる側＝PC、という設計そのものを卓上ルールにする。着地は**《ディビデンド》の味方への配当をPCへ支払う**＝協力関係成立の画。
- **《同一化》の「頭の痒みのような違和感」をカジノ編と同じ文言で再演すると、参加者が自力で気付ける**（伏線回収型の演出を作者は好む）。

### 【2026-09-18 作者判断】第3回の確定事項5件

1. **襲撃は案1で確定。** PCの出現自体が警報の原因。**第三者・陰謀・内通者は置かない。**
2. **漂流者登録の手続きは「かなり面倒」で確定。** 面倒さの具体化は台本側で詰めてよい（作者から明示の許可）。
3. **カージュ戦の形式は固定しない。** 「参加人数による／カージュなら複数人相手も不可能ではない／臨機応変でよい」＝**当日人数でGMが調整する設計にする。**
4. **ミラーズ戦は「ギミック攻略のような戦闘」。** 結末は**「大技を撃って実地試験終了」**で確定。**勝敗ではなく"データ収集"の達成で終わる。** 前回案のテンポ核（殴るほど不利／4ラウンド制限）は活かす。
5. **全体の結末は未定。作者の要望は「次のセッションにつなげる何かが欲しい」。**

**次回以降のセッション候補（作者構想／canon未記載）：テミス編（孤児院・院長エルネスト初登場。舞台は 07 の第128番艦《テミス》＝第4母艦《シバ》管轄）／月面宇宙基地編（ユニエラ・ジーヴル関連）。** 第3回の結末フックはこのどちらかへ直結させると価値が高い。

### 漂流者登録の面倒さ――公理を踏まずに書ける唯一の足場

**「制度上の扱い（保護／登録／監視のいずれに近いか）が未決」という02の穴を、そのまま面倒さの原因として使える。** 制度が未整備＝管轄が確定していない＝たらい回し。未決を解消せずに面倒さを描けるのはこの筋だけ。

- **窓口＝生命研究部門《アンテレイア》**なので、**書式が研究用**という一点で「生活の届けなのに学術アンケート」を成立させられる（新設定ゼロ）。
- **08の「届け出が面倒」は箱庭＝オラクル船団側の別制度。** 08 §Bパート整合性メモにより**同一制度として接続してはならない。** 台本では「また面倒な紙か」とPCが感じるだけに留める。
- **ルディアの手伝いは「名前の欄だけは代筆できない」で止めるのが最も強い**（彼女＝ロシェに名を与えた人物／01 §7-1）。テーマにも直結する。
- 《同一化》の違和感は**08 §の原文「頭の痒みのような、冷たい物を食べた時の脳の疼きのような違和感」を一字同じで再演**すると参加者が自力で気付く。

### 踏みやすい罠（この編で特に）

- **「漂着」を制度名・部門名に使わない**（02 確定設定）。「漂着届」は不可。**《デロイア》は存在しない。漂流者研究は生命研究部門《アンテレイア》（設立者ユニエラ）。**
- **ミラーズの戦闘参加は 01 §5-6 の【未決事項】。** 模擬戦を行う＝この未決を解消する判断になる旨を明示する。
- **三人（カージュ・ルディア・アヴリス）を「戦闘の達人」として描かない**（06 §3-0）。強さの根拠は常に生来の性質側。
- 「陰険クソメガネ」はネタとして触れてよいが**定義しない**（01 §6-3【要確認】）。
