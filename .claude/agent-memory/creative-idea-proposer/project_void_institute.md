**2026-09-14、作者の構想として固まった枠組み：** 02《研究統括部（虚空機関）》と、01 第II部§6／08§14 の「漂流者・残響物を研究する機関」（院長エルネスト・ノウトの元所属、ユニエラも関わり）は**同一組織**。全体を「虚空機関（ヴォイド）」とし、その内側に部門が細分化する。命名規則は **「[分野]研究部門：[分野]の虚《コードネーム》」**、既存例として **「生命研究部門：生命の虚《アンテレイア》」**。この全体呼称と既存部門名は作者確定につき変更不可。

**最重要・衝突回避の足場（提案時に必ず添える）：**
00§2-3／02 の「生命の虚《アンテレイア》」は**古代フォトナー離反者の研究・生活共同体**であって統合世界組織の部門ではない。「部門＝古代のアンテレイアそのもの」と読むと公理と衝突する。**00§4-3【有力設定】「古代の存在は統合世界では神話・昔話・古代英雄譚として残る」を使い、「虚空機関は部門コードネームを神話・古代英雄譚から採る命名文化を持つ＝引用／同名異義」と一行決めれば、名称を一字も変えずに両立する。**

**副産物：** この階層構造は 02 未決「『研究統括部』と『虚空機関』の関係」に **虚空機関＞研究統括部（統括部署）＞各研究部門** という答えを与える。03 の「統括部が評価し後に撤回」も「部門が起案・統括部が裁定」で読める。

**残響物・漂流者研究部門として提案した3案（2026-09-14、採否未定）：**
1. **漂着研究部門：漂着の虚《デロイア》** ― 02「物品として定着」＋「流れ着いた者」を一語で括る。漂う島が繋ぎ留められた神話。制度の冷たさ＝01§9-3 の「ユニエラ＝人として扱う／院長＝研究対象として扱った」対比が部門名で可視化。代償：02に「漂流者」独立項目の新設が発生しやすい。
2. **残響研究部門：残響の虚《レーテイア》** ― 漂流者＝人の形をした残響。02【確定方向】「別世界の自己情報と残響物の原理同一性は未確定」に対し**機関が"同一"側に賭けている学説**として立てる（世界の真実は確定させない）。語尾が《アンテレイア》と揃い姉妹部門感が出る。代替コードネーム《ムネモア》。
3. **境界研究部門：境界の虚《テルミナ》** ― 発生源（破れ目）で括る。境界標の神テルミヌス。代償：「境界の破壊＝ロシェ」なので、到達点を「破れ目は観測できるが、破ったのが誰かには至っていない」で一行止める必要あり。

**組み合わせ案：** 1を受理・登録の実務部門、2を性質解析部門として二部門併置。院長＝後者、ユニエラ＝前者に置くと01§9-3の対比が部門配置になる（「かつての同僚」と書かない制約は維持できる）。

**未使用の回収ポイント：** 03 EC-5493『それが一番大事』の「評価を後に撤回」＝どの部門の失態か本文が空欄のまま。

**踏まない線：** 08§Bパート整合性メモ（箱庭側の「漂流者を専門に研究してるおえらいさん」と統合世界の機関を同一制度として接続しない）／01「かつての同僚」禁止／**院長の一人称・口調は未決なのでサンプル台詞を書かない。**

**次の決め所：** 00§4-10「研究・情報・諜報系組織（代表カスラ）」傘下か独立系統か。決まると02の未決3件のうち2件が同時に埋まる。
