終の因果／終の因子まわりは本作で最も矛盾が発生しやすい領域。検査時はまずこの一覧と照合する。

## 確定設定の文言（改変不可の基準線）
- **00 §2**「**各世界には**、その世界が最終的にどのように終わるかという終端情報、『終の因果』が存在する」【確定設定】→ 終の因果は**世界側に元から属する**。ロシェの存在によって発生するものではない。
- **00 §9**「（古代【深遠なる闇】をハリエットへ封じる過程で）世界を終わらせるはずだった因果が凝縮・個体化する。それが終の因子＝シバ」【確定設定】→ 因果→因子の順。**因子が因果を生むのではない**。
- **02 終の因子**「終の因果が凝縮・個体化したもの」【確定設定】。**02 シバ**「シバとロシェは別人格ではなく、完全な同一人物」【確定設定】。
- **00 世界統合／02 世界統合**「終の因果**だけを**、ロシェ自身とともに世界の外へ**持ち出す**」【確定設定】→ 終の因果は**移送可能な実体**として扱われている。
- **02 世界外**「終の因果を**伴ったまま**世界外に存在している」【確定設定】。
- **02 統合世界**「最大の特徴は、**終の因果が存在しないこと**」【確定設定】。統合世界が特別なのはアカシックレコードに未来を記録されていないため。
- **00 最終章**「自殺：根本解決にならない／封印：古代ハリエットの再演になる／別世界への逃亡：終の因果をその世界へ持ち込むだけ」【確定設定】。

## 結合破壊の前例（「容器を壊せば中身も終わる」を否定する側の証拠）
- **00 §38 黒き邪竜**：肉体を破壊しても再生。「破壊対象そのものを間違えている」。容器破壊は無効という明示。
- **00 §50・§55 ルーサー編**：ロシェが結合を破壊しても【敗者】因子は消えない。ハリエットが受容し、オメガへ還元・排出する必要がある。**切り離した因子には受け皿と排出先が要る**。
- **00 §50**「ルーサー本人が『ルーサーとして残ろうとすること』が救出成立の**必要条件**」。
- **00 §25 ミトラ**：一時的に再現しても「因果が【敗者】を再計算するため失敗」。因果は token を除いても再成立する。
- **00 §44**「（ロシェは）異常な情報結合が成立した場合、その結合を**直接破壊できる唯一の存在**」【確定方向】。

## 未定義だが多重に荷重されている概念
- **「縁」**：02に項目が存在しない。にもかかわらず 05 §10（分離の根拠）／§14（終の因果の漏出経路）／§18（ロア生存の足場）の三役を負っている。最も弱いリンク。
