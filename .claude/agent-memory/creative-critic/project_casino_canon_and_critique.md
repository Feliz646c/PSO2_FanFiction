## 【意図的な保留】残響物の射程・正体

コルネオの残響物《エコーオブジェクト》の**正体・能力射程は、ユーザー判断で意図的に未確定・未説明のまま据え置かれている。**

- 04 §7【編集メモ：射程の扱いについて】：フィクスによる送還が「未確定の局所的事象への偏向」という定義で厳密に説明できるかは**確定させない。作中で誰にも解説させない。**
- **Why：** 奇跡・不可解な力の余地を残す方針。かつ今後のセッション・ストーリーへの影響を考慮し、いま明示しない。
- **How to apply：** 「送還は能力の限界に抵触する」を**矛盾として指摘しない。** 逆に、作中で誰かが射程や機構を解説していたら、それは【編集メモ】違反として指摘する。

なお§7【確定設定：能力の限界】そのもの（無から結果を創造しない／死者蘇生・人物創造・歴史書換・世界規模の因果決定は不可／強く作用するのは未確定の局所的事象）は現行のまま有効。送還だけが説明を保留された例外。

## 現行の確定項目（検査時のチェックリスト）

- **残響物による「勝ちきれない」偏向演出**（04 §7【セッション処理】）：原因を説明せず「異常なほど勝てない」現象として見せる。ルディアの手引き（情報優位）と競合しない二重構造。§9末尾で「§7の演出は本項によって無効化されない」と明記。
- **ルディアのイカサマは盤面工作でなく《同一化》による情報取得**（04 §9）。表＝軽口、裏＝心の声の二重チャンネル。
- **アヴリス・ルディアは所属名《ウルガル》・正体を最後まで明かさない**（04 §9【注意】・§13【注意】）。
- **コルネオは人前でフィクスを「主任」としか呼ばない**（04 §8）。
- **フィクスは残響物の性質を一切解説しない**（04 §15）。
- **§17の三者到達点**：フィクス＝目的達成／ロア＝目的未達（現物を失う）／ルディア・アヴリス＝部分達成。
