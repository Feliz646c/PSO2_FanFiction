2026-08-28、編集者（creative-editor）が提示した二層モデル（終の因子＝存在／終の因果＝世界と因子の間に成立する結合・関係）を、統合世界セッション最終決戦（05 §15〜§20）の文脈で検査した。**資料本体は未修正**。次回この話題が出たら、以下が解決済みか必ず確認する。

## 致命的として指摘した論点
1. 「関係モデル」は 00 §2【確定設定】（各世界に終の因果が存在する）と正面衝突。ロシェ不在の世界にも終の因果はある。
2. 「関係」は持ち出せない。02「世界外」「世界統合」の確定設定（伴ったまま／持ち出す）が無意味化する。→ **関係ではなく「移送可能な終端情報の実体」として二層化する方が確定設定を壊さない**。
3. 自殺無効の論理（因子が残るので因果が再成立）は、そのままロア破壊も無効化する。**05はロシェの最終的な所在を一度も書いていない**のが原因。
4. 「容器へ移して容器を壊せば完結」は本作が二度否定した手順（邪竜／【敗者】因子）。00 §9 の起源自体が「一個体へ凝縮した結果、完結せず千年存続した」実例。
5. 05 §17 のロアは「自ら破壊対象になる」＝残ろうとしない。00 §50 の必要条件と真逆。
6. 付着条件が二重（所在 vs 縁）。夢のロシェはキャンペーン中ずっとセッション世界にいたのに §14 まで接続しない理由が無い。
7. モデルを認めると最終章の必要性が崩れる。ロアは「滅びた世界全体を継ぎ接ぎの身体へ収容」した確定設定の容器、ハリエットは器。最終章で試さなかった理由が必要。

## 検査で判明した制約
- 二層モデルは **05・02への追記だけでは導入不能**。02の「世界統合」「世界外」「統合世界」および 00 §2 という【確定設定】に触れる必要がある。「00〜03を書き換えない」という制約とは両立しない。

## 繰り返し出る弱点パターン（このプロジェクト固有）
- 危機の解決が毎回「ロシェが結合を破壊する」（邪竜→ルーサー→シーナ→最終決戦）。最終決戦だけが**自己適用**で前例がない。
- 「未決事項」に機構の核心を残したまま、その機構を前提に構成を組む（05 §17・§18 が典型）。
