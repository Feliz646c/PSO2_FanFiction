00〜03（世界の公理）の確定設定・確定方向そのものを書き換える提案はしない。検証は 04・05 側、および 02 への追記案の妥当性に集中する。改善案は一言のヒントまで。

**Why:** 提案者は00〜03を「世界の公理」として固定運用しており（CLAUDE.md 整合性ルール）、公理を動かす判断は提案者の領域。批評者が代替案を構築すると提案者・編集者の役割を侵食する。

**How to apply:** 00〜03と矛盾を見つけたら「05／02側がこの公理に違反している」という向きで指摘する。ただし、**追記案が公理側の書き換えを不可避に要求してしまう場合は、その事実自体を指摘する**（公理を書き換える案は出さないが、「この案は公理を触らずには導入できない」という診断は範囲内）。
