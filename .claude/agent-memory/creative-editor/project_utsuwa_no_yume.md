2026-08-28確定。EP5オメガの正体に関する本作独自の説明。

## 核心（これが全て）
> **オメガとは、ロシェの中で眠るハリエットが、ロシェが壊した世界の残骸を器として受け止め、その材料で組み上げた「彼女が見たかった世界」である。**

**追加の特殊機構は一切不要。** ハリエットは元々「アカシックレコードを収容可能な器」として設計されており（既存確定設定）、**その設計目的がそのまま働いただけ**。

## 材料の流入
- **EP3**：ロシェがロアの起源世界（後の遺界）を滅ぼす。**滅ぼしたのはロシェ本人。** 完結した世界の歴史が初めて器へ落ちた。
- **EP3後**：破壊した並行世界の「情報」が器へ流入。フォトンは船団へ、情報は器へ。**ロシェは無自覚。**
- **EP4→EP5の2年**：器の中で情報が世界の形へ自己組織化。

## 派生する説明（すべて必然として導かれる）
- **能動機能が再現されない**＝夢の主が仕組みを知らないから。**素体特性が残る**＝そこが彼女自身だから。
- **意識リンクがロシェにだけ成立**＝オメガが彼女の内側にあるから。→**【有力案】から【確定方向】へ格上げ済み。**
- **ハリエットが「座標」**＝彼女が場所そのものだから。
- **姉妹・王女**＝ハリエットの願望由来。**本作で最も優しい形の「役割の付与」**（悪意はないが本人の意思を経ていない、という両義性を保持する）。

## 三つの由来（用語登録は「記憶深層」のみ）
| 由来 | 現れ方 |
|---|---|
| 記憶深層由来（実） | 硬い。勝手に自律する |
| 追想由来（半実） | 歪む。美化される |
| 願望由来（虚） | 整いすぎている。触れると壊れる |

**《記憶深層》**＝加工されていない他世界の記録層。「記憶」は**世界たちの記憶**。旧仮称（オメガ深層／深層記録領域／核記録層《カーネル》）は**使用しない**。

## 遡行召喚がハリエットへもたらすもの
穿孔対象はハリエットの内側そのもの。情報が全て彼女を通り抜ける。同時に二つ起きる。
- **自覚**：眠っていたハリエットが目覚める（01 §8-1「EP5で目覚める」の内実）
- **統合**：オメガ・ハリエットと一つになる。**ただし強制ではなく、オメガ・ハリエットが自分から手を伸ばす**（主題との整合上ここは譲れない）。統合後は**二人分の人生を持つ一人**。どちらも消えない。
- 鍵となる台詞：「あげるんじゃありません。**一緒に持つんです**」

## エルミル
**オメガの正体まで知っている。** ただしロシェの個人史は依然知らない（既存の非対称は維持）。宣告は「知らないことを教えない」ではなく**「知っていることを言わない」**。渡す答えは意図的に不完全。ロシェの到達は**「薄々」まで**。
検証表に**ヴェルン編の行を追加**（複合構造への到達＝06 §1-2段階6）。**ロシェが救出に成功した瞬間、【巨躯】因子がエルミルの手に落ちる。**
【巨躯】因子の出所＝EP1撃破後にロシェ（＝器）へ取り込まれ、シュレッガーが魔人化研究（**遡行召喚の粗悪な民間版**）で記憶深層から引き出しヴェルンで再構成した。

## 絶対に混同しない
| | 理由 | 性質 |
|---|---|---|
| **縁還り** | 誰かが覚えていたから | **奇跡** |
| **オメガの成立** | ハリエットが器だったから | **構造** |

## 使わないもの
原作の「アカシックレコードが見る夢」／ブラックホール・消滅エネルギーによるシバ帰還（00 §3-52と一貫させる）。

## 未決（この理論では扱わない）
オメガ住人の最終的な行き先／世界統合時のオメガの扱い／オメガが現実へ影響を及ぼし始める時期。
