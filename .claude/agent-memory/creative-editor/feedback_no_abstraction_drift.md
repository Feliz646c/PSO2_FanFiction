**作者が口頭・散文で述べた「理由」を資料化するとき、こちらの語彙で抽象化・一般化しないこと。** 具体的に挙げられた条件（職業・可視性・手続きなど）は、そのまま具体のまま書く。

**Why:** 2026-09-24、カージュがマトイの後見人であり得た理由を「革命メンバーの中で**社会的な立場を確立していた**のがカージュだけだったため」と書いたところ、作者から訂正が入った。作者の意図は「カスラは諜報、ルーサーは研究職で**表に出てこない立場**。カージュだけが企業の社長という**表に出やすい立場**だった」というもので、**立場の"有無"ではなく"可視性"の話だった。** こちらが選んだ「社会的立場」という抽象語が、他の人物から立場を奪う読みを生んでしまった（→[[project-ulgar-trio-abilities]]）。

**How to apply:** 人物の行動理由・資格・動機を【確定設定】として書き下ろすときに毎回。

- **「AだけがXを持っていた」型の文を書く前に自問する。** それは本当に**Xの有無**の差か、それとも**Xの性質・程度・見え方**の差か。後者なら「持っていなかった」と書いてはいけない。
- **抽象名詞（社会的立場・権威・能力・資格）へ丸める前に、作者が挙げた具体（社長／諜報／研究職）を本文に残す。** 抽象語は要約であって定義ではない。
- **対比を書くときは、比較される側の描写を必ず本文へ書き込む。** 「他方を否定するな」という注意書きだけでは足りず、他方が何を持っていたかを明記して初めてガードが効く。
- **理由付けは他人物の設定を削る方向へ働きやすい。** ある人物を成立させるために別の人物から何かを奪っていないか、書いた後に読み返す。
