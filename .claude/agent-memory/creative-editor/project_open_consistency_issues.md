2026-08-28に設定資料00〜05を一括レビューした際に指摘した論点。**未解決のものは、将来の提案でうっかり片側だけを前提にしないこと。**

## 04↔05の食い違い（最優先）
- **ロアの動き**：04はロアを牢に入れたまま終わる（コルネオが「幸運値がマイナス」と言って参加者だけ解放）が、05 §7は「参加者に陽動を頼み、ロアは裏で調査を進める」と書いている。→ 提示した解決方向：04 §5の牢内会話でロアが陽動を依頼する台詞を足し、脱出契機（治安維持部隊突入の混乱／ルディア・アヴリスの手引き）を04側に明記する。
- **カジノ編の結末が05へ返っていない**：残響物はフィクスが回収して去るため、ロアの調査は目的未達で終わる。05 §7に「調査結果」を追記する必要がある。
- **運用ルールの非対称**：04には「参加者側の設定は本資料で確定しない」があるが、05はユーニを【確定設定】として定義してしまっている。

- ~~03のロシェ発言の記録主体~~ → 匿名クレジットへ差し替える方針で決着。

**【未解決】**
- **世界統合の適用範囲**：「無数の並行世界を一つに」と言いながら、セッション世界は別世界として存続している。02へ「統合世界と因果的に接続していない世界は存続する」という注記を入れる案は出したが、境界を定める条件は未決のまま。
