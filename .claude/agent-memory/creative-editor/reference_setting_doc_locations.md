**設定資料の置き場所は一定ではない。作業前に必ず `Glob **/*.md` で実際の所在を確認すること。**

2026-09-14時点で確認された状態（**提案者によるディレクトリ再編が行われた**）：

```
Agent/
├── CLAUDE.md          # ルート直下固定
├── .claude/           # ルート直下固定（エージェント定義・永続メモリ）
├── canon/             # 00,01,02,03,06,07,08 ← 確定設定マスター
```

## 押さえておくべき点

- **`04_カジノセッション構想.md` は存在しない（2026-09-14に削除確定）。** 開催前の構想資料だったため役割を終え、提案者が意図的に削除した。**内容は `canon/08_カジノ編確定設定.md` へ統合済み。** 旧本文は初回コミット `e602d97` から `git show e602d97:"01.PSO2関連/セッション資料/Agent/04_カジノセッション構想.md"` で取得できる。
- **05だけ canon/ に無い。** `sessions\開催セッション\05_統合世界セッション構想.md` にある。
- 資料内の相互参照は**ファイル名のみ**の記述で統一されている（パス表記はしない）。この慣例に合わせる。
- CLAUDE.mdの資料一覧表は2026-09-14に新構成へ全面更新済み（06・07・08も掲載済み）。

## 【重要】ログが読めない場合がある

`.docx` はバイナリのためReadで開けず、Shift-JIS のテキスト書き出しもReadでは文字化けする。**Bashが無効なセッションではログ本体を読めない。**

その場合は、`sessions\開催セッション\...\セッション情報.md` の**「ストーリー」節**（卓で読み上げられた本文そのもの）を次善の典拠として使う。**ただしPCのアドリブとGMの即興応答は拾えないため、その旨を明記して作者に照合を依頼すること。**

### 台本代用の限界は実証済み（2026-09-14）

2026-09-11カジノ編を**台本だけで**資料化した初版には、ログ照合で**15項目の誤りが見つかった**（→[[project-casino-canon]] の08 §13-B）。しかも誤りは細部ではなく、

- **クライマックスの攻略法そのもの**（「賭けに持ち込む」→実際は完全アドリブの無力化）
- **用意した演出が使われたかどうか**（失敗時の一文は一度も使われていない）
- **NPCの台詞の逐語**（存在しない台詞を引用していた）

といった中核部分だった。**台本には「GMが読み上げる予定だったもの」しか書かれておらず、卓上で何が採用され何が落ちたかは分からない。**

**How to apply:** 台本を典拠に資料を作る場合、**「予定」と「実際」を区別できないという限界を資料内に明記し、ログが読めるようになったら必ず再照合する。** 作者にUTF-8プレーンテキストでの書き出しを依頼するのが最短。

**How to apply:**
- Read/Edit の前に必ず Glob で実在を確認する。パスを信じて決め打ちしない。
- 移動が起きていたら、勝手に戻さず作業対象を実体に合わせたうえで報告する。
