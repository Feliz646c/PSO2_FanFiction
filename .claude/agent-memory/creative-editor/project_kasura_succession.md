**2026-09-24 に提案者の決定として確定。** canon/00（§3-5・§3-12・§4-5・§4-10・§4-20）、canon/01（第I部§1・§6-1・§10-1・§10-3・§17・§19）、canon/02（§9・§12）へ反映済み。旧本文の移送先は `changelog/00_世界設定マスター.md` 2026-09-24。

## 確定した構造

- **「カスラ」は個人名ではない。襲名される役職名・通り名。** 時期によって指す人物が違う。
- **初代カスラ＝ルーサー本人。** 名の初出は**統合前の世界でオラクル船団へ潜入した際の名乗り**。後にカスラを辞し、**研究統括組織《虚空機関》の代表**となる。
- **二代目カスラ＝ルーサーのクローン。本名不明。** 初代が用意した後継者で、**研究・情報・諜報系組織の代表**。
- **00 §3-12 の「第二カスラ」＝二代目カスラ**（別表記であって別人ではない）。**旧世界では初代→二代目の継承がEP2より前に完了**しており、同じEP2でルーサー本人は「シオンへ到達し【敗者】となる」という別の道行きを歩む。核心思想「元老にも、ルーサーにも、誰にもアークスを所有させない」は**二代目のもの＝自分を名指す言葉ではない。**
- **統合世界でも同じ襲名が独立に起きている。** 00 §4-20（《黎明の転舵》期）の「カスラ」は**初代＝ルーサー本人**。**旧世界と統合世界で継承時期が一致しなくても矛盾ではない**（それぞれ別に再構築された歴史での出来事）。**片方の時期をもう片方へ持ち込まない。**
- **現在（A.P.244）研究・情報・諜報系組織の代表を務めているのは二代目。ルーサー本人ではない。**

## 踏んではいけない線

- **「カスラ＝ルーサー」とだけ書かない**（初代のみ）。**「ルーサーが研究・情報・諜報系組織の代表」とは書かない**（それは二代目）。**訂正前の00 §4-20「後世、研究・情報・諜報系組織代表となる」は誤りとして削除済み。復活させない。**
- **虚空機関と研究・情報・諜報系組織は別系統の並立組織**という既存確定は**一切変わっていない**（→[[project-void-institute-canon]]）。**「ルーサーが分身を代表に据えて二組織を掌握している」という筋を導かない。**
- **クローンの機構・経緯・技術・時期を説明しない。** 確定は「初代が用意した後継でルーサーのクローン」「本名不明」の二点のみ。**人格・記憶・能力の異同、両者の現在の関係性は未決。**
- **襲名の制度（誰が指名するか／公職の手続き／三代目以降の有無）は未決。**
- **統合世界で初代がこの名を使い始めた経緯は未決。** 潜入という由来は**旧世界の話**であり、統合世界へそのまま持ち込まない（→[[project-axioms-tripwires]] 4）。
- **01 §19 の【要整理】から第二カスラを外していない。** 解消したのは**同定だけ**で、性格・思想・関係性は未整理。**役割から個人設定を逆算しない。**

## 同時に確定した運用（生存人物一覧の扱い）

- **00 §4-5／01 第I部§1 の「ユニエラ、ルーサー、ミトラ、ヴァルナ、カージュ、ルディア等も統合世界では生存している」という列挙は例示であって網羅的な境界ではない。** 「一覧に無いから統合世界に存在しない」と読まない。逆に**存在を示すために名前を足していく必要もない**（名簿ではない）。
- **統合世界は無数の並行世界（旧世界を含む）が境界を失って一つになったもの。旧世界にいた人物が統合世界にも存在すること自体は特筆すべきことではない。**
- **ロシェは終の因子・終の因果ごと自分自身を世界外へ持ち出した。** 旧世界の出来事のうち**ロシェの存在に絡んだ因果**（誕生・隠蔽・革命・EP1〜5）は統合世界では「そもそも起きなかった歴史」。カージュ・ミトラらが死なないのは**死ぬ理由となった因果が発生していない**から。**一方、ロシェに絡まない出来事は旧世界と統合世界で独立に起こり得る**（実例＝カスラの襲名継承）。
- **「復活・転生・移住ではない／統合世界の人物は統合世界の人生を生きてきた」という公理は不変**（→[[project-axioms-tripwires]] 4）。
