## 確定したこと

- **氏名：エルネスト・ノウト。**
- **経歴：（元）漂流者および残響物を研究する機関の研究者。現在は在籍していない。**
- この経歴によって、**漂流者と残響物の双方について制度の内側の知識を持ち、記録に残さず現物へ手を伸ばせる伝手を保持している。**
- **コルネオへ残響物を流したのは、組織の事業ではなく院長個人の行動**（→[[project-casino-echo-object-canon]]）。フィクスの言う「クライアント」＝**院長個人**。

## 動機の正本（2026-09-14（9）に大幅拡張）

**【確定方向】「研究者時代の無力感と『救世主』への転落」が01 第II部 §6へ新設された。** 【確定方向】「嫉妬の原点」を**置き換えず、その原点と経緯を詳述する**位置づけ。骨子：

1. **院長自身は漂流者ではない。救おうとしていた側。** 嫉妬の原点は「自分も帰りたい」ではなく「**なぜ自分にはこの人たちを救う力がないのか**」。
2. **【確定・2026-09-14（10）】研究対象は残響物側。** 彼は**残響物の解析を通じて、失われた世界の実在と、その滅亡を確認していた**（＝《レーテイア》の職掌のまま）。**「漂流者への直接調査」と書かない。部門跨ぎ・移籍案は不採用。** 解析が精緻になるほど「その世界は確かに存在したが既に滅びている、故に帰れない」を証明してしまう。**知識は増えるが救済する力は増えない**＝根本的な傷（この構造自体は不変）。
3. 孤児院は当初本気の救済。しかし**無力を毎日突きつける場所**にもなった。
4. 「なぜ自分にはないのか」「なぜあいつにはあるのか」→嫉妬の成立。**妬んだのは戦闘力ではなく「世界の在り方を決められる立場」そのもの。**
5. 「誰か救ってくれ」→「ならば自分が救う」→「救わなければならない」→「**何が救いなのか自分が一番よく知っている**」。
6. **能力の本質（破壊）を誤認**し、「作り直せる力」だと思っている。**ロシェが自らの意思で世界外へ出たことも理解していない。**
7. 手段化（漂流者・残響物・ジーヴルの怒り・ゲルニカの力・フィクスの虚無・最終的に当人）。**ただし本人に「利用している」自覚が薄い**（「彼らの願いを叶えるために力を使っている」）。
8. 最大の矛盾＝**当事者に代わって救済を定義する。** 要約：「帰る場所を失った者を救いたかった人が、誰がどこにいるべきかまで決める人になった」。

## 禁じ手

- **既存の【確定設定】【確定方向】の文言を書き換えない。** 氏名が決まっても呼称は原則「院長」のまま。**作者は「既存の確定文言は書き換えず追記」を明示的に求めた。**
- **経歴は「手段」の説明であって「動機」の説明ではない。** 動機の正本は【確定方向】「嫉妬の原点」＋上記の転落過程。**「研究者だったから残響物に執着している」という筋へ横滑りさせない。**
- **院長の「破壊ではなく作り直せる力」という理解は誤認であり、ロシェの能力設定を変更しない**（→[[project-axioms-tripwires]] 2）。誤認を他ファイルへ事実として波及させない。
- **院長を「善意の人」として描き直さない。** 客観的には利用、**主観においてのみ救済**という二重性を必ず保つ。
- **最終用途（残響物を何に使うのか）とは接続しない。** 入手経路が決まっても最終用途は未確定。
