## 確定したこと

1. **ルクネリアの妹の名は「オルネリア」。** 姉妹は両親を亡くし、二人でオラクル船団へ移住してきた（＝帰る場所がない）。**この事情はカジノ編本編で一切開示されていない。**
2. **保護されたリリーネ人9名**（ルクネリア／オルネリア／フィオリナ／リリン／ネリン／リーナ／ルナリエ／リュミエーリ／ヴァネリア）が、**約1年後にBAR『NightFall』を開業する。** **リリーパ星系への帰還は採られていない。** 主題「生まれた理由と、生きる理由は同じではない」の着地。
3. **【最重要】リリーネ人はオラクル船団内で法的人格を持つ。戸籍の登録と渡航記録が存在する。** 02 §14 の【未決事項】は解消（→[[project-species-axis]]）。**「無権利だから売買されていた」と読まないこと。逆で、制度上記録の残る人々が商品にされていたという形で加害は重くなる。**
4. **カージュの人物像：** 喫煙／多忙／ぶっきらぼう／**最終的に部下の裁量を尊重する。** 最後の一点は「これは俺の命だ。俺が決める」の部下への適用として読む。**「面倒見の良い上司」に丸めない。**
