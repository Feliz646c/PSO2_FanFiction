**提案側が発案した固有名詞・組織単位（部門名など）を、作者の明示的な承認なしに【確定設定】として資料へ書き込まない。** 承認前は**【要確認】**または**【有力案】**に留める。

**Why:** 2026-09-14、漂着研究部門《デロイア》を【確定設定】として00・01・02・05・08へ一斉展開した直後、作者から**「私はデロイアを正式設定として認めてません。アンテレイアが漂流者の研究も担当している、としています」**という訂正が入った。撤回作業が5ファイルに及び、各所へ【撤回設定】を残す必要が生じた。**作者の「分割しましょう」という指示は「既存部門と新設部門に振り分ける」意味ではなく、「新設するのは一方だけで、残りは既存部門が担当する」意味だった。**

**How to apply:**
- **「分ける」「切り分ける」という指示を、自動的に「両側に新しい入れ物を作る」と読まない。** 既存の器（既存部門・既存用語）で受けられる側は既存のまま置く読みを必ず併記して確認する。
- 新語を資料へ入れる前に、**「この名称を正式設定として登録してよいか」を単独の質問として出す。** 登録と同時に他資料へ横展開しない。
- 横展開する場合は**正本（02）を先に確定させ、参照側（00・01・05・08）は正本を指すだけの記述**にしておくと、撤回時の傷が浅い。
- **撤回時は削除せず【撤回設定】として残す。過去の【更新履歴】は改変しない**（→[[project-doc-conventions]]）。参照側には「撤回された／要点は変わらない」形の【修正】注記を足す。
- 撤回で**所属・帰属が空白になる人物**が出ないか必ず確認する。空白が出たら埋め直し案を【要確認】で添える。
