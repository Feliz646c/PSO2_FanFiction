**2026-09-14に作者決定として確定し、canon/00 §4-10・canon/02 §9・canon/01（§9-3／§10-3／第II部§6）・canon/08 §14へ反映済み。**

## 部門の正式名称（2026-09-14（6）確定／（7）二部門へ改訂）

- **形式は「［分野］研究部門：［分野］の虚《コードネーム》」で統一。** 「［分野］研究部門《コードネーム》」は**略記として有効**（他資料の既存記述は書き換えていない。この略記ルールで整合を取っている）。
- **登録済みは二部門：生命研究部門：生命の虚《アンテレイア》／残響研究部門：残響の虚《レーテイア》。**
- **【撤回設定（2026-09-14（7））】漂着研究部門：漂着の虚《デロイア》は不採用。** 作者の明示**「私はデロイアを正式設定として認めてません。アンテレイアが漂流者の研究も担当している、としています」**による。**「漂着」を部門名・制度名として使わない。**
  - **【2026-09-17 現行版／変遷史の分離を適用】02側の記録は移送済み。** 本体 `canon/02` §9 には**【確定設定】《デロイア》という部門は存在しない**という項目が**同じ位置に**あり（他資料の「02 §9の同項」という参照が切れないようにするため）、**旧本文・撤回の経緯は `changelog/02_用語マスター.md` 2026-09-17（2）**にある。00 §4-10・01 §9-3・05 §8・08 §0/§14側の撤回記録は**未移送のまま残っている**。
- **漂流者研究は生命研究部門《アンテレイア》が単独で担当する。** **（6）で書いた「《デロイア》との管轄の重なり」「現象そのもの／生命として」の切り分けも同時に撤回済み。管轄の重なりは存在しない。**
- **【確定（2026-09-14（8））】ユニエラ＝生命研究部門《アンテレイア》の設立者であり、同部門に所属。** 作者決定。**「単なる所属研究員ではなく、部門そのものを彼女が設立した」**（作者の言：ユニエラが部門自体を設立したと考えるのが自然）。**部門名も本人による命名＝偶然の一致ではなく意図的な命名。** 00 §4-10・01 §9-3・02 §9・05 §8・08 §14へ反映済み。**職名・役職（部門長かどうか）は依然未確定。**
- **名称の一致は「淡々とした事実」。作者は今後の描写・伏線に使う予定がないと明言。** 「彼女は何かを感じ取っていた」等の示唆・伏線めいた書き方をしない。**同名異義・後継組織ではない・統合以前の記憶に由来しない（＝神話からの引用という命名文化に従う）という既存の確定は全部そのまま生きている。**
- **01 §9-3【未決事項】「アンテレイア相当共同体の有無」は部門設立では解消されない**（部門は研究組織であり、古代の「家族に近い共同体」ではない）。資料にも明記済み。
- **他の人物が名称の一致をどう受け止めるかは引き続き未決**（02 §9【未決事項】。ユニエラの分だけ解消した）。
- **「アンテレイア」の語源＝anti（反する）＋teleia（完全・完成）＝「反完全」**（canon/02 §2「生命の虚《アンテレイア》」に【確定設定】語源として追記）。残響物・漂流者との響き合いは**語義の重なりに留め、因果関係を作らない**（作者の明示指示）。

## 確定した構造

- **《虚空機関（ヴォイド）》＝統合世界の研究統括そのもの。** 組織それ自体が統括であり、**「虚空機関＞各研究部門」の二層**。
  - **【撤回】「虚空機関＞研究統括部（統括部署）＞各部門」の三層の読みは不採用。** 提案者が一時想定していたが却下された。蒸し返さない。
  - 03_残響物カタログの表記**「研究統括部（虚空機関）」は、公的記録上の機能名による言い換え**として整理した。**03の本文は一字も変更していない。**
- **代表者＝ルーサー**（01 §10-3【確定設定】社会的立場）。ルーサーの未決は「研究内容／ユニエラ・ハリエットとの関係／全知への執着の程度」の三点のみに縮小。**立場から動機を逆算しない。**
- **カスラの「研究・情報・諜報系組織」とは別組織・独立系統で並立。** 根拠は既存確定文**「一般科学研究のすべてを独占する組織ではない」**。**カスラ側の文言は不変。**
  - **【2026-09-24 追記】この「カスラ」は二代目（ルーサーのクローン／本名不明）であり、初代カスラ＝ルーサー本人。** ルーサーは**初代カスラを辞した後に虚空機関の代表となり、研究・情報・諜報系組織の代表は後継＝二代目に継がせた**（→[[project-kasura-succession]]）。**並立という構造は一切変わっていない。「ルーサーが分身を通じて二組織を掌握している」という筋を導かないこと。**
- 部門（正式名称は上記の通り。以下は略記）：
  - **生命研究部門《アンテレイア》**＝生命一般＋**漂流者研究**。**設立者かつ所属＝ユニエラ（確定）。**
  - **残響研究部門《レーテイア》**＝残響物の性質解析。**院長エルネスト・ノウトの元所属**（離職済み）。
  - 《レーテイア》の「漂流者＝人の形をした残響」という学説は**【有力案】止まり**（世界の真実として確定させていない）。

## 踏んではいけない線

- **部門コードネームは神話・古代英雄譚からの引用＝同名異義。** 古代の「生命の虚《アンテレイア》」と部門を**制度的に**つなげない（根拠：00 §4-3【有力設定】）。**生命研究部門は名称が古代と完全一致するが、後継組織ではない。** **【更新（8）】命名者がユニエラ本人であることは確定したが、これは「同一人物が二度同じ名を使った」という事実まで。ここから先（記憶の残留・予感・伏線）へ踏み込まない。ユニエラは統合以前の記憶を原則持たない（01 §1）という公理は不変。**
- **ユニエラと院長（レーテイア）は別部門。面識・在籍時期の重なりは未決で「かつての同僚」と書かない**（既存制約は維持されたまま）。**ユニエラの部門名が未確定でも、この「別部門」という要点だけは書ける。**
- **虚空機関を院長の実行組織にしない。** 残響物の流通は**院長個人の行動**、「クライアント」＝院長個人（08 §14）。
- **ルーサーと院長の接点は一切未決。** 代表者確定を院長と接続しない。
- **08 §14はGM専用・非公開のまま。** 機関名が確定しても03へ書かない。
