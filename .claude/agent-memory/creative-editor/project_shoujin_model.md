2026-08-28、三度の改訂を経て**最終形**に到達。**私が過去に出した二層モデル・三層モデル（原因と結果の対）・「置く／手渡す」版は全て撤回済み。持ち出さない。**

## 4行要約（これが全て）
> ロシェは、個体化してしまった終わりである。だから、どこにいても世界を終わらせかける。
> ロアは、滅んだ世界の最後の一人である。彼が終われば、その世界はようやく閉じる。
> ロアは、自分の終わりに彼女の終わりを相乗りさせ、彼女には何も告げずに斬った。
> 二人が戻ってきたのは、誰かが覚えていて、誰かが願ったからである。

## 中核
- 終端情報はどの世界にも当たり前に存在し、**通常は静かにあるだけ**。**ロシェの起源世界の分だけが、古代の一度きりの事故で意思を得て個体化した。移動するのは情報ではなく彼女自身。**
- 成立条件＝**①所在＋②抑止の解除**。**《半確立》＝個体化した終の因子が自分の根源ではない世界にいる状態。** → **ロアが受け取っても彼の根源は起源世界なので統合世界に半確立は生じない。だから切り離しは不要。**
- **《抑止》**＝ロシェの意思＋ユニオラル。千年終わらなかったのは因子が保存されていたからではなく**ロシェが望まなかったから**。
- **遺界**＝ロアの起源世界。終端情報は**既に成立している**。閉じない理由は**最後の体現者ロアが生きているから**だけ。22年閉じなかったのは**彼が終わる選択をしてこなかったから**。物理法則ではない。
- **離断**＝結合の切断ではない。**ロシェという存在を一時的に崩す。特別な技術は要らない、ただ斬るだけ。合意なし、単独、不意打ち。**
- **相乗り**＝ロアが自分の起源とともに終わるとき、ロシェの終の因子も一緒に閉じられる。
- **代償はある。ロアは死ぬ。**「破壊される生命は一つも無い」は撤回。戻れる保証もない。
- **縁還り**＝**技術ではなく奇跡**。要るのは①誰かが覚えている ②本人に未練がある、の二つだけ。**それ以上の原理は設定しない。** 戻るのは**一個の生命として成立してからの生涯＝ロシェは約20年**。千年分ではない。
- **ユニオラル**＝「損なわせない鎧」。判定は**その干渉でロシェが損なわれるか否かonly**。**合意不要。** 今回だけ通るのは**帰る場所（縁）があるから**。**院長には永久に不可能――彼は縁を用意していない。**
- **最終章で使えなかった理由**＝物理法則ではない。**統合世界のロアがまだ生まれていなかったから。** ハリエットが《シバ》に賭けた未来とは**まだ生まれていない誰か**のこと。

## 削除済み（二度と書かない）
引力／アカシックレコードの樹の伝播則／遺界が刃になる／外科手術的な結合切断／判定タイミングの凍結／縁還りの三先例論証（残響物・別世界の自己情報・ユーニ）／記録外世界限定条件／見極めの二用途拡張／「破壊される生命は一つも無い」／**ロシェとロアが協力しているという前提の全表現**／ロシェによる切り離し手順／ユーニの「橋」機構。

## ユーニ
「橋」ではなく **「道」**。ロシェとロアは協力していないので繋ぐ必要がない。参加者を**ロシェのいる世界の外まで運ぶ**役。既存実績の応用のみで新設定不要。

## 実行順序（15手）
1ロア単独で参加者へ依頼／2ユーニが道／3ロシェが歓迎（目的は縁の破壊、歓迎は最後のわがまま）／4対峙（**負けイベント**）／5過去を知る／6再対峙・未練を残させる／7ロシェが自ら縁を切り直そうとする／8**ロア単独の不意打ち**／9ロシェ成立しなくなる／10参加者がロアへ敵対／11遺界へ／12最後の情報と対峙・看取る／13ロアが起源とともに終端実行・走馬灯（起源世界のラル）／14消尽・ロア成立しなくなる／15縁還り（**ロシェ→第4母艦《シバ》／ロア→セッション世界**）。院長の退場はこの表より前。
