00〜03（世界の公理）のうち、提案で最も踏み抜きやすい「地雷」を絞り込んだリスト。提案を出す前に毎回照合する。

1. **シバ＝ロシェは完全同一人物。** 別人格・憑依・後付け上書きではない。「ロシェの中のシバ」という表現は禁止（逆に「ロシェの中にハリエット」は正しい）。
2. **ロシェの能力は「破壊」のみ。創造はしない。** 扉を作らない／境界を壊す。新しい状態を定義できないため、救済には必ず本人の抵抗＋周囲の支援が要る。ロシェ単独万能解決の構図にしない。
3. **統合世界内部に「統合世界のロシェ」は存在しない。** 世界外で眠っている。第4母艦《シバ》はロシェ本人でもコピーでもなく「空の器・帰る場所」。
4. **統合世界の人物は統合世界で生まれ、統合世界の人生を生きてきた。** 旧世界人物の「復活」「転生」「移住」ではない。例外はロア／ジーヴル／ゲルニカ／フィクス／ミラーズの「別世界の自己情報の残留・混入」のみ。
5. **オメガ個体は古代フォトナー由来の能動的能力を使えない。** 受動的な素体特性（ハリエットの器容量など）だけが残る。例外はロシェのみで、それは現実側との意識リンク経由という説明。
6. **ロシェはハルコタンへ行ったことがない。** 原作EP6（終の女神シバの外部からの帰還・終の艦隊戦）は発生しない。
7. **七つの大罪モチーフの人物は全員が敵ではない。** ミラーズは初期から協力側。
8. **統合世界にダーカー／ダークファルス／【深遠なる闇】は実在しない**（神話・御伽噺として残るのみ）。リヴォア・ダーカーはゲルニカの具現化作品。
9. **テーマの根幹**：「一人の命を犠牲にして多数を救うことは許されるのか」／「その人の命の使い道を誰が決めるのか」／「生まれた理由と、生きる理由は同じではない」。自己犠牲そのものは否定しない。否定するのは**他者から用途を与えられること**。この線を越える提案（役割ゆえの犠牲を美談化する等）はしない。
