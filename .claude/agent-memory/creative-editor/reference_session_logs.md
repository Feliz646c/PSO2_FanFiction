実施済み／準備中セッションの台本とログは `設定資料\` ではなく **`個別資料\<YYYYMMDD>セッション\`** にある（`セッション情報.md`＝進行台本、`セッションログ.txt`＝実ログ、`ショートカット.md`＝発言用スニペット）。

- `個別資料\20260815セッション\` が05のいう**第1回統合世界セッション**に相当する。ユーニ登場・トランクケースへの入眠・ナベリウス・リヴォア・ダーカー・ロア登場までが台本化されている。
- `個別資料\20260911セッション\セッション情報.md` は**カジノ編の実行台本として書き起こし済み**（2026-09-10時点で確認）。図書館→カジノ→応接間→牢→フロア→VIPルーム→コルネオ戦の進行、NPCの特徴描写、バニーガールの名前割り当てまで含む。
  - **この台本と04が食い違う場合、提案者は台本を正とする**（2026-09-10、警備員バニーA／Bの特徴で実際にこの裁定が出て04 §10を台本へ寄せた）。04は「セッション運用のための上位構想」、台本は「実際に喋る内容」という関係。
- 05は「実際のセッションログでも〜」という形でログを根拠に設定を確定させているが、**05本文にログの所在が書かれていない**。ログ側の記述と05の記述にズレがある例あり（ログではユーニは「ちび冥シリーズNo13／ロシェをマスターとして憑いている」、05では「統合世界でユニエラをマスターとして縁が成立」）。

**How to apply:** 05の【確定設定】の根拠を検証するとき、および参加者側キャラ（ユーニ、UoC関連など）の扱いを判断するときは、必ずこのフォルダを先に読む。参加者側キャラは他者の持ち物なので、資料側で断定する提案はしない。
