00〜03の根幹原理に触れる提案を出すときは、以下を必ず自己検査する。

1. **確定設定の名詞を「実は関係だった」と読み替えない。** 私は「終の因果＝世界と終の因子の間の関係／結合」という二層モデルを提案したが、00 §2・02は「終の因果は**各世界に存在する**終端情報」と実体として書いている。定義のカテゴリを勝手に変えるのは、整合させたつもりで公理を書き換える行為だった。**採用された《消尽》モデルは、実体という定義を保ったまま「未実現／実現・消尽」という状態変化を足すことで解いている。この解き方が正解パターン。**
2. **作中で既に否定された手法を、別の場面で解として再提案しない。** 私は「終の因果を引き受けたロアを破壊して完結させる」という05の既存案を補強したが、「容器を壊しても中身に届かない／対象を間違えている」は黒き邪竜編とルーサー編で**二度**否定された、この作品の核心的教訓だった。
3. **本作の救済成立条件を満たしているか確認する。** ルーサー編・ヴェルン編の型＝「本人が内側から抵抗する」「本人が残ろうとすること」が必要条件。ロアは「自分はあの世界の最後の残骸だ」と思っており**残ろうとしていない**ため、私の案は救済の必要条件を満たしていなかった。
4. **「なぜ今までできなかったのか」に答えられるか。** 新しい解法を出すときは、過去の時点で同じ手が使えなかった理由を必ずセットで用意する。**最終的な答えは「まだその人物が生まれていなかったから」という人物の話だった。**
5. **★物理法則を足して説明しようとしない。** 私は改訂のたびに機構（引力・伝播則・切り離し・輪郭判定・凍結）を足して整合させたが、**最終形ではそれらが全て削除され、「誰が何を選んだか」という人物の意思の話へ収束した。** 説明が破綻したときの正しい対処は、法則を足すことではなく**登場人物の選択に還元できないか探すこと**である。
6. **奇跡を根拠で補強しない。** 縁還りの成立根拠として先例3件を積み上げたが却下された。理由は「根拠を積み上げるほど、これが奇跡であることが薄れる」。**この作品では、説明しないことが正しい場合がある。**

7. **★能力の制約条件から、能力の使い方を勝手に「受動的な現象」へ弱めない。** 2026-09-09、ルディアの《同一化》が片務型（一方通行）であることから、私は04 §9のイカサマを「情報が筒抜けになるだけで本人は何もしていない」という受動的な形へ書き換え、作者に訂正された。正しくは**戦場の司令塔運用と同じ二重チャンネル（口では別の話をしながら「心の声」で伝える）の転用**。片務型＝「他者を変えない」という制約であって、**本人が能動的に振る舞えないという意味ではない。** 制約は行使の意思を否定しない。**能力の適用場面を考えるときは、まず「本人が既にやっている運用の転用で説明できないか」を先に探す。** 新しい説明を作る前に、確定済みの運用を再利用する方が常に採用されやすい。

**Why:** 提案者はこの案を私・proposer・criticの三者に投げて検証させた。批評者が7件の致命的矛盾を挙げ、提案者が《消尽》モデルを出して統合された。私の案は単独では通らなかった。

**How to apply:** 根幹原理レベルの提案では、断定的な改稿案として出す前に「この案は00 §Xと衝突しないか」「作中で既に否定された構造ではないか」を明示的に自己検証した節を付ける。自信があっても、公理に触れる案は【要検討】として複数案を並べる方が結果的に速い。
