## 確定した機構――《連結決算》

作者の決定：「機構案としては3。長期戦（長期投資）になればなるほど、巨大な一撃を打てる。カードゲームでいうコントロール型」。

- 対象の**体外**へ外付けフォトンタンクを取り付け、**対象へ加えられた干渉の余剰・散逸分**を集める。**味方の攻撃分も含め、誰の攻撃かを問わず無差別。**
- **相手のフォトンの内側には一切入らない。奪わない。対象の側に損は生じない。**
- **固定の閾値による満期が無い。** 戦闘が長引くこと自体が価値。タンクの本数も増やせるため長期化が二重に効く。
- 収穫**《ディビデンド》**の支払先は二択＝**自分（単発の大火力）／味方（配当・分配）。** 同じ蓄積の支払先違いであり、二つの能力ではない。
- 爆発**《リキデーション》**は**収穫より格下**。「この対象からはもう何も得られない」ときの損切り。**主力の攻撃手段として描かない。**
- **代償は体質ではなく装備・運用の制約**（在庫・高コスト＝攻撃回数が実質「予算」・投下に接近か射線・即効性なし・敵が自力で外せる）。**「早く終わる戦い」に弱いのは設計そのもので、場面ごとに免除しない。**

## 採用した命名セット（金融・会計語彙＋社内型番）

体系**《連結決算》**／工程**《インベストメント》《アキュムレーション》《ディビデンド》《リキデーション》**／大鎌**MRG-00《グレート・ハーヴェスト》**／タンク**MRG-00S《シードマネー》**。

**Why:** 「ミラーズ＝経営・金融用語＋社内型番」という命名文化が既存方針で、計画出身者の和語一語（「隕落」）と対照をなす。農事語彙・漢語は計画出身者側の語感に寄るため採らなかった。《連結決算》は作者が案3として言及した語をそのまま体系名に残したもの。

**How to apply:** 追加の技を作るときも同じ語彙圏から取る。**軽い採用であり、作者が差し替えを望めば名称だけ差し替えて機構は動かさない。**

## 必ず守る禁じ手（本体にも【確定設定】として明記済み）

1. **「臨界」をミラーズ側で使わない。** ラルの《エクスカリティ》（06 §2-3）の語。ラル＝精密制御で自ら限界域へ／ミラーズ＝制御せず満ちるのを待つだけ。彼女が決められるのは「いつ引き出すか」だけで、これは制御ではなく**判断**。
2. **「溜めて爆発させる能力」と要約しない。** 中核は回収と支払い。
3. **蓄積を加速・操作していると書かない。** 積み増しの過程へ手を出せない。
4. **相手のフォトンを「吸う／奪う／削る」と書かない。** カージュの《蝕み》（06 §3-4＝内側へ干渉して残す）との差がここで消える。
5. **タンクを首に付けない。** 拘束具を連想させる位置・形状にせず、相手の動作も妨げない。**08 §11 のリリーネ人の首輪（爆弾入り）と絵面を分けるための確定事項。** 拘束ではなく計器・容器として描く。
6. **ミラーズを「最強のアークス」計画の枠（06 §3-0）へ組み込まない。** 力の出所は技術・装備・資本。

## 【2026-09-18 確定】非戦闘員だが兵装で戦える

作者の判断：「ミラーズは、基本的には非戦闘員です。アークスではないため、一般人の枠を出ません。ただし、兵装による補助などで『戦う事ができる人』になれる認識です。今回も、パワードスーツのような物を身にまとって戦うでしょう」。**01 §5-6に【確定設定】戦闘上の立場 を新設／06 §3-7に【確定設定】使用者本人は非戦闘員である を追記。**

- **ミラーズはアークスではない**（ARKS資格の未決はこれで解消）。**基本的に非戦闘員＝一般人の枠を出ない。**
- **《ミラージュ》製の兵装（パワードスーツ類の強化装備）による補助で「戦うことができる人」になる。**
- **大鎌《グレート・ハーヴェスト》の運用も兵装補助を前提とする。素の身体能力だけで大鎌を振るう描写にはしない。** 既存の一文「大鎌を実際に扱うことができるだけの身体能力を持つ」は削除せず、直下に【精緻化】注記を置いて「兵装前提で読む」と明示した。
- **禁じ手：** アークスとして扱う／熟練・鍛錬の成果として強さを説明する／兵装なしで戦闘へ立たせる／「実は戦えた」という底上げをする。**兵装は「隠された素質」の言い換えではない。** 力の出所は一貫して技術・装備・資本。
- **兵装の正式名称・型番・機能は未確定。新規固有名詞は作っていない（02 §13へも未登録）。** 必要になったら06 §3-7の命名規則（金融・会計語彙＋社内型番）に従う。
- 01の2026-09-18（1）【解消記録】にある「戦闘要員として扱わないこと」は**注記ブロックで置き換え済み**（記録自体は原文保存）。**その一文だけを読んで戦闘参加を否定しないこと。**
