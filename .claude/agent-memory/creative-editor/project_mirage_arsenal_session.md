## 「虚空機関」の名前を伏線として出す（canon反映は最小）

作者の意図：「ここで参加者側に『虚空機関』というワードを提示することで、伏線を張ります（虚空機関は原作で言う悪の研究機関であるため、一部参加者は警戒するはず）」。

- **canon反映は 02 §9 への【運用上の注意】一件のみ**（名称の響きから警戒・懸念を抱かれやすい／機関の実際の性質・行動の是非とは独立に起こり得る）。
- **【最重要】「虚空機関は実は悪の組織」という設定を足していない。** 警戒は**参加者のメタ知識（原作）由来の反応**として設計されている。**本作の虚空機関の善悪を資料側で確定させない。** 院長の実行組織にしない線も不変。
- **漂流者を制度上どう扱うか（登録・保護・監視）は依然未決。** この未決こそが「たらい回し」の原因なので、**解消しないまま使う。**
