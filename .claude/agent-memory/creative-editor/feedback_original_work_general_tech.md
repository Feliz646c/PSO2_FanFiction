**作者が人物の説明の中で出した語を、自動的に「その人物固有の設定」として登録しない。** 原作（PSO2／PSU系統）に既にある**一般技術・一般名詞**である可能性を先に疑い、判断がつかないときは**登録位置そのものを【要確認】として作者に問う。**

**Why:** 2026-09-19、カージュの武装確定の際に「ナノトランサー上に大量携行」という一文から**ナノトランサーを02 §13（個人固有の能力・装備）へ登録**したところ、作者から**「これはPSU系統で登場した原作由来の一般技術（四次元ポケット状の収納装置）であり、船団全域に流通している」**という訂正が入った。**収録位置を【要確認】として残しておいたため訂正は一日で済み、傷は浅かった**（→[[feedback-new-terms-ratification]] の《デロイア》では5ファイルの撤回作業になった）。**【要確認】を付けておく運用自体は有効だったので継続する。**

**How to apply:**

- **登録前に「この語は作者の創作か、原作由来か」を必ず分ける。** 原作由来なら、人物項ではなく**一般技術・制度側の節**へ置く。カタカナの装置名・機関名は特に疑う。
- **原作由来と判明した語は、この世界での位置づけ（誰が使えるか・どこまで普及しているか）だけを確定させ、機構は説明しない。** 原作で説明が無いものは本作でも説明しないのが作者の方針。
- **とくにフォトン・情報粒子の体系へ接続して原理を与えない。** 接続すると「フォトンを扱わない者は使えない」ことになり、一般技術という位置づけと衝突する（02 §12 アークスの定義と照合）。
- **原作側の固有名詞（星系名・組織名など）は持ち込まない。** 作者の説明文に出てきても、本作canonに前例が無ければ本文へ書かない（資料内にPSU系の固有名詞は一件も存在しない）。
- **一般技術と判明しても人物側の確定文は書き換えない。** 「その技術を使っているだけ」と読める注記を一行添えるだけでよい。**多くの場合、むしろ人物の既存設定（カージュなら「武器にこだわりを持たない」）と整合が良くなる。**
