2026-08-28確定。ロシェとハリエットの能力を切り分ける理論。**正本は06 §1-5、用語定義は02。**

## 核心（1行）
> **ロシェが目の前の現実を綻ばせ、器（ハリエット）の残りがその空隙へ別の記述を写す。どこからも奪っていない。写しているだけであり、写した先で何も減らない。**

## 三段構成
| | 名称 | 由来 |
|---|---|---|
| 前提 | **《観測》** | 器（ハリエット） |
| 工程① | **《綻び》** | 終の因子（ロシェ） |
| 工程② | **《重ね書き》** | 器（ハリエット） |

- **《綻び》は06 §1-2の7段階表の外。** 段階2・3（世界境界破壊）とは規模も系統も違う。表に行を足さず注記のみ。
- **複製であって移設ではない。参照元は何も失われない。外部への代償ゼロ。**
- **《観測》は探索ではなく受容。** ACへの自由アクセスではない（00 §3-23と一致）。
- **創造ではない。** 実在する記述しか写せない。00 §3-1（無からエネルギーを生まない）とも非衝突。同項の「他世界から力を得る」は境界破壊を伴う**別行為**。

## なぜ器の性質が残るのか
シバは**ハリエットの器の内側で個体化した**。器の中で生まれた事実が彼女の成立に含まれる。世界統合で失われたのは器そのもの（ハリエットという生命）であり、**内側で生まれた者に刻まれた性質は残る。** ただし本体でないため容量は極小。**オメガ・ハリエットの素体特性の論法（00 §3-23）と同型。**

## 旧世界では発現しない
器が内側にあった間、受け取った記述は全て器へ流れ込み溜まっていた（00 §3-14＝オメガの材料）。分離で溜まる先が消えたため、**その場で重ねる以外に行き場がなくなった。同じ受容で行き先だけが変わった。** よって世界統合以降の現象。

## トランクケース
**世界外へ出るとき「世界を旅したい」と願った彼女自身が、夢の中の自分へ持たせたもの。** 二役＝①世界外との接点 ②常設の空隙。
- **物品は保存していない。** 空隙へ「そこに物がある」という記述が重なるだけ。選べない。
- **接点であって所在ではない。** よって終の因果を波及させず、**危機の規模は変わらない**（05 §14）。
- **能力の源ではない。** 空隙常設なので工程①を省略でき精度が上がるだけ。無しでも行使可（小規模・短時間・不安定）。
- 決着後：接点の役割は終わるが空隙の性質は残る。**旅の荷物になる。**

## 縁還り後も失われない
06 §1-4の喪失対象（転嫁・世界境界破壊）に含まれない。**失われるのは世界を終わらせられることであり、重畳は世界を壊す手段ではない。**

## 制限4つ
①実在する記述のみ ②空隙は一度に一つ ③**連用不可・危険はこちら側**（広げすぎると周囲の現実が崩れる。**実セッションで本人がトランクを閉じて中断した実績があるため確定設定扱い**）④差の大きい記述は届かない。

## 運用上の禁止
- **台詞例・演出例を資料へ書かない**（作中でこの能力の詳細を知る人物が少数のため。作者の明示指示）。
- **語彙統一**：「引き出す/持ってくる/取ってくる/奪う/借りる」は使わず**「綻ばせる/重ねる/写す/書き換える」**。ただし02既存確定文の「観測可能な並列世界の可能性を持ってくる」のみ現象の平易な記述として保持。
- **06 §1-4の既存2項目と末尾未決事項は変更禁止。注記追加のみ。**
- **「最終段階でロシェの能力は一切使用されない」（06既存確定）は維持。** 重畳は最終決戦に一切関与しない。
