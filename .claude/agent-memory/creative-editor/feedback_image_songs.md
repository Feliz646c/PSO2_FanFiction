**イメージソングから得られた人物解釈は、それだけで自動的に【確定設定】【確定方向】へ昇格させない。** 提案者から明示の昇格指示がある項目だけを格上げし、他は**【有力案】または【解釈補強】（確定より一段低い扱い）**で追記する。

**Why:** 2026-09-14（9）に七名分の心理深掘りを反映した際、提案者が明示した方針。曲の情緒に引きずられて人物の核が書き換わることを避けるため。**唯一の例外としてエルネスト・ノウトの転落過程だけが【確定方向】へ格上げされ、フィクスの「なくしもの」だけが曲として正式採用された。** 他は全員「候補扱い」。

**How to apply:**
- 曲名を書くときは**【有力案】イメージソング候補**という見出しにし、末尾に「**候補であり、正式採用ではない**」と必ず添える。
- 解釈は既存の【確定設定】【確定方向】を**書き換えず、その内側の説明として重ねる**。見出しは「【解釈補強】」が使える（2026-09-14（9）で採用された）。
- **心理解釈を人物本人に自己分析として語らせない**旨の【運用上の注意】を添える（ゲルニカ・フィクスで明示的にそうした）。
- 歌詞由来の語（例：カージュの「闇」）が既存用語と衝突する場合は、**比喩であり既存固有名詞とは無関係**と明記する（【深遠なる闇】／ダーカーとの混同回避）。
- 名前の語呂読み（ルディア＝Dear you 等）は**作者側のイメージ覚書であり語源設定ではない**。02へ登録しない。
