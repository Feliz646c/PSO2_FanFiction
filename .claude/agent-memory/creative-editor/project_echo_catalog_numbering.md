**2026-09-14、03残響物カタログの番号体系が `No.001`〜の通し番号から `EC-XXXX`（4桁）へ全面移行した。**

**Why:** 元ネタがSCP財団であり、**発見順・整理都合で番号がバラバラに散る**という質感を再現するため。作者の直接指示。

## 確定したルール

- **EC番号は連番ではない。** 発見順・整理順・危険度のいずれも反映せず、**欠番・空き番号が多数存在する**前提。近い番号どうしに関連性はない。**新項目を追加するとき、既存番号の続きを振らないこと。**
- 桁数は常に4桁。上位が0でも省略しない（`EC-0261`）。
- 一度付与した番号は変更せず、撤回されても他の物品へ**再利用しない**。
- 定型ヘッダ1行目は `オブジェクトEC-XXXX『名称』`。「オブジェクト」の接頭辞は旧書式から維持している。分類／危険度／記録の3行は無変更。
- **旧規則「通し番号は No.001 から採番し、欠番を作らない」は、2026-09-17に `changelog/03_残響物カタログ.md` へ移送した。** 本体の【確定設定】表記規則には**否定形の禁止事項として**「旧番号形式（`No.XXX`）は使用しない／連番採番は適用しない」が残っている。**消さない。**

## 【確定設定】1,300点

- **統合世界でEC番号を持つ残響物は1,300点確認されている。** カタログに詳細記載があるのは**そのごく一部**（現在7項目）で、大多数は未整理・未詳細のまま存在する。
- **確認総数と収録件数の不一致は「正常な運用状態」**と明記済み。埋めるべき欠落として扱わない。
- **EC番号は確保・記録が成立した物品にのみ与えられる。番号を持たない異常物品は1,300点の内数に含まれない。** これは08 §14（コルネオの残響物＝公的記録に残らないため03へ登録しない）と整合する書き方であり、**GM専用情報には一切触れていない。**
- **分類が「トランクケース由来」でもEC番号の付与対象。** EC番号は由来ではなく統合世界側の記録成立を示す、と各欄の定義に明記した（EC-0672フランスパンがこれに該当）。
