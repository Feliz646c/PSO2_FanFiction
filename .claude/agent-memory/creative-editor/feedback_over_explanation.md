**描写を厚くしてよいと言われても、（1）固定の段取りを積み上げない（2）人物に自分の内面・抑制・手加減を解説させない。**

**Why:** 2026-09-18に作者から「カージュは能力を使わせず、単純なる戦闘技術で魅せてもいい」と言われ、10/09台本の模擬戦②を**四段構成（間合い／見切り／複数／一撃）＋詳細な連続技描写**へ書き込んだ。2026-09-21、作者はこれを**「過剰な説明であり、彼の寡黙な人物像と矛盾する」**として撤去させ、**GMが当日の参加者の行動に応じて選ぶ"引き出し"2〜3個**へ置き換えるよう指示した。同時に「今日は使わん」「これは俺の命だ。俺が決める」「手加減はした。能力も使っていない」という**自己解説の台詞も全削除**された。

**How to apply:**
- **「魅せる」＝「細かく書き込む」ではない。** 卓上運用の文書では、**固定の順序を持つ長い演出より、GMが選べる短い指針**のほうが価値が高い（**ダイス判定なしのセッションでは特に**）。
- **禁止・方針・要点はGM注記へ、絵は本文へ、順序は作らない。** 「この段の次はこの段」と書き始めたら書きすぎのサイン。
- **寡黙なキャラには寡黙なまま結果を出させる。** 制約（能力を使わない等）は**地の文とGM注記で担保**し、本人に宣言させない。**自分の思想・抑制を説明させると人物像が壊れる。**
- **同型の既存教訓と合流する：** 説明を能力側・台詞側へ寄せると却下される（→[[feedback-metaphysics-proposals]]）、手順書は書かず機構を書く（→[[project-adlib-canonization-policy]]）。
- **裏返しの注意：** 削るときも**確定設定に紐づく禁じ手（素手で終わらせる／直撃させない／名称を出さない 等）は必ず残す。** 削ったのは段取りと説明台詞であって、ガードではない。
