2026-09-10に02へ§14「種族・星系文明」を新設し、リリーパ族／エルジマルト人／リリーネ人を最小定義で登録した。

**間違えやすい線引き：**
- **アークス＝フォトナーが生み出した分類**（00 §4-7／02 §12）。**エルジマルト人が作ったリリーネ人はアークスではない。** 「兎耳の種族もアークスの一種」と書かないこと。
- リリーネ人は04・05カジノの**従業員バニーガールの背景設定**。ルディア・アヴリスは潜入者であり**リリーネ人ではない**。
- ~~種族全体の法的地位・市民権は**未決**。~~ **【2026-09-17 確定】リリーネ人はオラクル船団内で法的人格を持ち、戸籍の登録と渡航記録が存在する**（02 §14に【確定設定】として追記済み／典拠は後日談 `stories\Nightfall.docx`）。**「無権利だから売買されていた」と読まないこと――逆であり、制度上記録の残る人々が商品にされていたという形で加害は重くなる。** 参政権・就労制度・移住要件などの内訳は引き続き未決。**戸籍を持つことを根拠にアークスへ接続しない。**
- **保護された9名は帰還せずBAR『NightFall』を開業する**（→[[project-nightfall-afterstory]]）。**種族全体の傾向として一般化しない。**

**Why:** 元の記述は20260911セッション台本のメモ節1行だけで、リリーパ族・エルジマルト人も未登録だった。周辺を埋めるとき、アークスの定義（フォトナー由来）や「オラクルは銀河連邦ではない」という公理と衝突しやすい。

**How to apply:** 種族・外部文明に触れる提案では02 §14を先に読む。掘り下げは04 §10【運用方針】（バニーガールは深掘りしない）に従い、脇役NPCの背景以上には広げない。主題「生まれた理由と、生きる理由は同じではない」との接続は使ってよい（02 §14に【参考】として明記済み）。
