## 最終確定（同日、proposer・criticとの検証を経て）

私の初稿から**覆った**もの。再提案時に旧案を持ち出さないこと。

- **終の因子／終の因果**：私の二層モデルは却下。**《消尽》モデル**で確定 → [[project-shoujin-model]]
- **ユーニのマスター**：私は「(a)ロシェで一貫」を推奨したが、**ユニエラで確定**。ロシェとユーニは懐かれている姉妹のような間柄。台本の「ロシェをマスター（？）」表記は**参加者への意図的なミスリード**という設定。
- **03のロシェ台詞**：私の(c)「二次記録」案は不採用。**匿名クレジット（「とあるアークス」等）へ差し替える**方針で確定。削除ではない。03全体を洗い直した結果、ロシェ台詞はEC-3149『黒歴史保全委員会』とEC-8025『オーレ！』の2箇所のみ（2026-09-14の番号体系移行前は No.002／No.003 → [[project-echo-catalog-numbering]]）。
- **ジーヴルの漂流者設定**：(a)採用。制度上の「漂流者」定義があり本物も実在する施設。ジーヴルは**自己情報の混入により自分を漂流者だと誤認していた**。その混乱が周囲からもそう扱われる根拠になった。
- **ユニオラルの転嫁**：ロシェは能動的な搾取も受動的な転嫁も**EP3時点で既に自覚している**。「なぜこんな力を持って生まれたのか」は無知ゆえの問いではなく、知った上で答えが出せていない問い。EP4の救済は能動的搾取の停止のみに限定され、転嫁は継続していた。
- **世界統合の年代**：**世界統合＝世界誕生そのもの。** 統合前の期間という概念が統合世界に存在しない。A.P.暦は住人が後から定めた社会的な暦で、統合という事象と厳密には対応しない。数値確定は不要。
- **アヴリス**：(b)本作NPCで確定し、全項目が【確定設定】へ。女性18歳／黒髪三つ編み・メガネ・目閉じ／一人称「私」／2〜3音区切りの口調／長刀／統合世界生まれで旧世界には存在しない／「最強のアークス」計画が長期継続した末の末っ子／《ウルガル》内3〜4番手／ルディアが個人的に可愛がっている。
- **エルミルの宣告**：「未知の事実の暴露」ではなく「ロシェが既に抱えていた問いへの、誤った回答の突き付け」として書く。
- **機械的作業（00の見出し再構成／03の定型ヘッダ／01の術式群を06へ分離）**：全て実施承認済み。
