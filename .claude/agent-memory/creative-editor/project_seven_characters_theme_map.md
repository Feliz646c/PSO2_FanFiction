**2026-09-14（9）に提案者から提供された横断整理。** 01本体へは反映していない（提案者の指示で反映不要）。**今後の提案・批評で人物間の一貫性を保つための基準として使う。**

## 共通の軸

本作の命題「**その人の命の使い道を誰が決めるのか**」「**生まれた理由と、生きる理由は同じではない**」に対し、**七人はそれぞれ異なる位置で同じ問いに答えている。**

| 人物 | 罪／テーマ | 命・意味に対する立場 | 到達点（または留まった地点） |
|---|---|---|---|
| **ルディア** | ― | 生まれつき与えられた意味を否定。永遠でないことと価値がないことは別 | **自分の人生を生きた末に、自分で命の使い道を選んだ** |
| **カージュ** | ― | 兵器として生まれた事実を否定しない | **力の所有権を自分へ取り戻す。「誰のために使うかは俺が決める」** |
| **ロア** | ― | 記憶を持つ自分だけができる→**やらなければならない**へ変質した強迫観念 | **故郷も罪も消さず、未来の側へ生きる** |
| **ゲルニカ** | 傲慢 | 自分の輪郭を他者／もう一人の自分に定義されることへの恐怖 | **見られても解釈されても自分は消えないと理解する** |
| **フィクス** | 怠惰 | 失い続けた末に何も抱えない防衛。**選ぶこと自体が面倒** | **「面倒でも、本人が生きたいなら終わらせない」へ進めるか**（未到達） |
| **ジーヴル** | 憤怒 | 苦しさを扱える形（怒り）へ変換して生きている | **生死を決める権利を自分の手へ取り戻すこと**（他者の承認では届かない） |
| **エルネスト** | 嫉妬 | 救えなかった側。**当事者に代わって救済を定義してしまう** | **命題の最大の違反者。転落の完成形** |

## 使い方（重要な対応関係）

- **カージュ ↔ フィクス**：同じ「誰かの刃」だった場合、カージュは「俺が決める」へ進み、フィクスは選ぶこと自体を放棄した。**ただしこの対比はテーマ上のものであり、両者の実際の関係・同期は未確定**（01 第II部 §4【最重要・未決事項】）。
- **ジーヴル ↔ エルネスト**：ジーヴルに必要なもの（自分の生死を決める権利）を**最初に奪ったのが院長**。救済方向と加害構造が鏡像。
- **ルディア ↔ エルネスト**：ルディアは自分で使い道を決めた。院長は他人の使い道を決める。**同じ「命の使い道」の両極。**
- **ロシェ（§2-1 マトイへの台詞）↔ エルネスト**：ロシェが一度犯した失敗を、院長は**世界規模で恒常的に**行う。
- **カージュ「お前の命だ。俺のために使うな」**が、院長の在り方の正反対。

## 禁じ手

- **自己犠牲そのものは否定しない。否定するのは他者から用途を与えられること**（→[[project-axioms-tripwires]] 9）。この線を越える提案をしない。
- 救済の**可否**は人物ごとに確定していない。テーマ表を根拠に「救われる」と確定させない。
- フィクスの救済方向、ジーヴルの救済方向はいずれも【有力案】止まり。
