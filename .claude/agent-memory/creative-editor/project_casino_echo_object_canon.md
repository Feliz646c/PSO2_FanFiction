**正本は `canon\08_カジノ編確定設定.md` §14【GM専用・非公開】。2026-09-14（3）に機構が全面確定した。**

**03残響物カタログには登録しない**（現物をフィクスが持ち去り、公的な押収記録に残らないため）。

## 意匠

- **透明なガラスケースに収められた三つのサイコロ。** 目にした者は言いようのない悍ましさを覚える。コルネオは上着の下、胸元に携帯。
- **旧04の「骨製のサイコロ」「GM内部仮称《賽筐》」は撤回。** 02へ登録しない／内部呼称としても復活させない。
- 02「ロシェのトランクケース」とは完全な別物（掌大／旅行鞄で峻別）。

## 【最重要】機構（2026-09-14（3）確定・これが最上位の定義）

- **フォトン（＝情報）を改変し、使用者が望んだ可能性を現実へ挿入する異常。**「望みが叶う」のではなく、望んだ結果が"もともとそうだった"かのように書き込まれる。
- **旧「未確定の局所的事象への偏向」は否定されていない。** 現象の外形を述べた旧記述に対し、こちらが内側の機構。**矛盾ではなく精密化・上位互換。**
- **コルネオの幸運＝本人の「自分は常に幸運の強者である」という自負（願望）が現実化したもの。** 具体的な願い事はしていない。**自己像がそのまま挿入内容になるため、意識的な発動も接触も不要。** これが「望みが単純な被験者」という選定条件の中身。
- **【幸運の相対性／ゼロサム】幸運も不幸も比較対象がいなければ決定できない。周囲（コルネオ以外）が幸運になるほど、コルネオの幸運は相対的に薄れる。** 攻撃せずとも削れるのが急所。運否天賦の勝負へ持ち込むほどラッキーが起こらなくなる。
  - **世界の側に「幸運の総量」という法則があるわけではない。個体の仕様。** 残響物一般へ拡張しない。

## 公式の攻略法（GM側の想定解。カテゴリであって手順ではない）

1. **幸運勝負で勝つ（真っ向勝負）** ―― 周囲を幸運で満たし相対的に削り切る。
2. **異能無効化等でテーブルごとひっくり返す（イカサマ）** ―― 幸運というルールの成立自体を潰す。
3. **力で押し通る（力こそが全て）** ―― 「宇宙が壊れてもお前は生きていられるのか」の水準。
4. （第四の選択肢）**確保・収容・保護。** ただし**収容方法が定まっていない種類のオブジェクト**のため難易度最高。今回選ばれなかった理由。

**今回の実プレイは①の実例。** 「囚われた娘（ルクネリア）を助ける」「スロットでジャックポットを引かせる」は、いずれも**場に他者の幸運を発生させてコルネオの相対優位を削る行為**だった。参加者は機構を知らないまま正確に①を踏んでいた。

> **【区別を厳守】機構の説明は書く。攻略手順は書かない。** §14は"攻略本"ではなく"筋が通っているかを判定する物差し"。**「娘を助けてジャックポットを引かせれば勝てる」という形で再利用しない。** §4F・§16の「参加者が現場で組み立てた」という注記は今も有効（→[[project-adlib-canonization-policy]]）。

## 実戦で観測された挙動

- **偏向は「外れる」ではなく「別の対象へ向け直される」。** 撃った側・味方へ返る。**自己像が「自分より運の悪い者がいる」形まで含めて現実化するため。**
- **目減りする**（「消費して空になる」ではない。**残量ゲージとして扱わない**）。
- **回復する。** 手元にある限り時間経過で補填（「#老人の幸運は、補填されていた――」）。**他者の幸運は一過性で、自負そのものは損なわれていないため。速度・上限は定義しない。**
- **外部干渉を受ける。**「確定を遅らせる」魔術干渉が通り、**現物を盗もうとする行為そのものが効果を「縫い止めた」。**
- **所在は隠せない。** 探知で「常にこの老人と共にある」まで割り出せた。
- **数値・射程・回復時間は一切示されていない。表やパラメータに落とさないこと。**

## 【言葉遣いの厳守】

- **「確定事象」という語を使わない。** 02の終の因果・半確立とは無関係。**「フォトン（情報）の改変」と書いたことで終の因果へ接近したわけではない。**「趨勢」「成り行き」「可能性」と書く。
- **卓上の「因果の選別」「固定」は描写語であって用語ではない。** 02へ登録しない／終の因果と接続しない。

## 流通経路＝院長個人の行動（2026-09-14（4）確定）

- **院長＝エルネスト・ノウト。（元）漂流者・残響物研究機関の研究者**（→[[project-incho-ernest-nout]]）。
- **元研究者としての知識と伝手を使い、組織の事業としてではなく個人の行動として裏社会へ流した。**
- **したがってフィクスの言う「クライアント」は機関ではなく院長個人。組織ぐるみの陰謀として描かない。**
- **経歴は「手段」の説明であって「動機」の説明ではない。** 動機の正本は院長のテーマ「嫉妬」。**「研究者だったから残響物に執着」へ横滑りさせない。**

## 院長組織の意図＝実地試験（新機構と整合済み）

- **直接渡していない。賭けで負けてみせ、コルネオに「巻き上げた」と信じさせた**（01「独立した犯罪者」を維持するため）。
- 流した理由：**意図を持って観測する者の手元では観測行為自体が偏向の対象になり、正確な測定ができない。** よって①原理を理解せず②**自己像が単純で強固**（金・女・勝ち、そして「自分は幸運の強者」という自負）③未確定事象が高密度な環境を自前で持つ人間に使わせ、外から観察した。
- 回収理由：**摘発が寸前で、公的な押収記録に残る前に回収する必要が生じたため。**
- **【最重要】院長が最終的に何へ使うのかとは切り離す。** 両者を接続する記述を書かない。

## 開示範囲＝GMの裁量による意図的な開示（2026-09-14（3）確定）

- フィクスは地下水道で**「"実験"、らしいぜ？」「クライアント曰く、な。」**と言っている。**これは開示範囲の事故ではなく、GMがアドリブで意図的に切ったカード。** 作者いわく「参加者に情報を提示する事自体は悪い事ではない」。
- **既知：依頼主が存在すること／目的が実験であること。** 未開示：依頼主が院長であること・実験の目的・賭けで渡した経緯・観測理論・機構そのもの。
- **この二語を「今初めて明かす情報」として演出し直せない。** 次に切るのは必ず一段深いもの（誰が／何のために）。
- フィクス自身も伝聞でしか語っていない（「らしいぜ？」）。**「何も知らない実行役」にも「全部知っている共犯者」にもしない。**

## 【確定】「誰も自分でサイコロを振らない」という含意は一度だけ破られた（2026-09-14（4））

- **コルネオ側は設計どおり。** 懐に入れたまま、触れずに「カラン、とダイスが振られる音」が鳴る。**振られていることにすら気付いていない。**
- **フィクスは「ガラスケースを、サイコロを――振るった」。** 初版の「傾けただけ」はログの字句と食い違う誤記。
- **作者判断で「破れ」を採用。フィクスはこの物語で唯一、自分の意思で賽を振った人物。**「維持される読み」（ケースを振っただけ）は【撤回設定】。**ただしケースが開かれていない事実は有効。**
- **【最重要の未決】フィクスは何を望んで賽を振ったのか。** 機構上、望みが必ず伴う。だが作中に一切示されていない。**「PC達を排除したかった」と単純化しない**――実際に遠ざけられたのは**PC達ではなく「この男の目的を阻む可能性」のほう。** 本人に語らせない（台詞は「あばよ、漂流者。」「今度会った時は、まぁ……酒でも奢ってやるよ。」のみ）。08 §15-Bに明記。

## 台詞は設定を補強している

フィクスの語は**「取り立て」「取り立て。持ち主に返す。」**（旧04の「使える奴のとこに持ってくだけだ」から変更）。**賭けで取られた物を回収するのだから文字どおり取り立てであり、フィクスは一言も嘘をついていない。** PCもロアも含意に気付かず「要領を得ない返答」として処理された。**今後もこの語彙で通し、説明させない。**
